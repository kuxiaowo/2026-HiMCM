## 1. 研究范围与本轮目标

研究对象为整个埃托沙国家公园。第一题定义保护优先事项与可量化保护标准；第二题直接配置地面保护人时与无人机机时；第三题建立人力需求与排班可行性模型，第三题不使用预测模型。第一版以道路进入便利度代理偷猎压力，以历史晚旱季过火比例表示火暴露；数量和法定保护类别构成选定动物的区域保护责任，植物与重点栖息地保留独立分项。

用户于2026-10-05要求开始正式建模，先完成空间分区，并持续记录过程用于论文写作；必要时并行使用子代理。当前阶段的交付目标是可叠置道路、生态、水源、火灾和降水资料的完整公园分区，以及能够匹配历史动物表格的区域编号。

本轮不将分区生成等同于完成资源优化、生态指标计算或资源效果验证。现有资料来自不同年份，只能支持静态规划示范；不能据此宣称得到2026年的全园实测现状。

## 3. 采用的空间尺度原则

### 3.1 动物统计单元优先，生态类型在区内保留比例

第一版优先以2015调查统计单元作为动物数据支撑尺度，而不是立即按林地、草地等重新切区。原因是已有数量表在调查单元尺度成立：若转为新的生态小区，必须另作面积或适宜生境分摊，分摊结果不是新小区的实测数量。生态类型以各区面积比例参与可燃生境、重点栖息地和缺失分布估计，避免重复给同一动物价值加分。

15个来源键为`ENP1`、`ENP2`、`ENP3410`、`ENP5`、`ENP6`、`ENP7`、`ENP8`、`ENP9`、`ENP11`、`ENP12`、`ENP13`、`ENP14`、`ENP15`、`ENP16`、`ENP17`。源表面积逐行求和为18,551.1375 km²，与报告汇总18,551.14 km²的差异来自显示精度。

调查中的`ENP3410`合并了原`ENP3`、`ENP4`、`ENP10`三个编号；第一版保留为一个数量统计单元。不能把合并总量拆为三个独立的实测分区数量，也不能因编号含四位数字而认成四个原单元。若几何由多个面组成，应保留同一`region_id`并以多部件几何或同编号子面表达。

### 3.2 全园覆盖与未知值

15调查单元排除主盐沼。主盐沼和其他无法可靠匹配调查图的范围仍须纳入全园分区，使用单独编号及数据状态。调查外动物字段为未知/null，不填零；其鸟类、植物、水域和栖息地价值不能由大型动物缺测推成零。任何额外边界残差区都应有独立标记，不将它隐蔽地并入邻区以假装拥有调查数量。

### 3.3 公开坐标与图件的证据等级

本轮起初计划使用报告图1的JPEG配准重建；随后取得非洲象数据库与2015调查对应的15个公开坐标单元，方法改为以公开坐标为基础、依据报告图核对后做拓扑修复，并裁切到所选OSM公园边界。取得坐标后不再将主方案称为纯手工描图。本轮JPEG仅作结构目视核对，没有实施地理配准，因而不报告虚构控制点或配准残差。主盐沼采用残余几何形态法近似提取，并与报告图结构对照。

公开地图保留`ENP3410`合并统计键，修复后仍有3个实质部件；`ENP11`最终为1个主体，不把两个图上标签解释成两个独立统计区。新增主盐沼`PAN_MAIN`和调查外残余`UNSURVEYED_OTHER`，保证全园研究范围不因动物缺测而丢失。接口未显式声明坐标系，源核查按经纬度量级推断WGS84/EPSG:4326，应保留这一假设。来源地图坐标存在量化与概化，不能称官方GIS、官方管理区或精确生态边界。

来源核查显示坐标步长约0.002703213°，对应当地约284—299 m刻度；这是坐标量化特征，不是实际位置误差保证，也不称300 m栅格产品。接口各项直接保存MultiPolygon及properties，规范化仅补标准Feature包装并保留原坐标。网页许可标为CC BY-NC-SA 4.0，来源和许可随原始材料保留；报告、接口和两张图件的SHA-256见`data/regions/raw/source_audit/source_manifest.json`。

原图西南无编号条纹块缺明确图例，实际航迹图也未显示对应调查航线，不能强行并入ENP1；其具体含义仍待资料核对。ENP13/ENP11的小于0.1 km²源孤立部件已按明确阈值转入残余，并记录面积；没有从全园研究范围删除。

所有修复须保存原坐标、区号归一化规则、报告图核对依据、重叠分配优先序、裁界面积与剩余范围。若辅助图件需要配准，另记控制点、变换方法和残差；不能把取得公开坐标误写成已取得原始调查GIS。

源表面积用于动物调查密度和数量核验；数字化几何面积用于空间叠置，并单独保存。两种面积出现差异时不默认缩放原数量，不利用面积拟合反过来证明边界准确。只有明确的空间分摊情景才将原数量重新分配，并保存来源和总量守恒检查。

## 4. 降水数据不足时的实施安排

空间分区不依赖每个区域是否有雨量站。本轮可先完成分区和字段结构，不伪造区域降水差异。

只有全园资料时，采用全园共享的年度或情景因子`R_y`。只有12个月长期均值时，先描述季节基准，不能得到某年的距平；尚无目标雨季雨量时以明确标记的偏干、正常、偏湿情景测试配置。取得格网数据后，按像元与区域相交面积计算区域平均月雨量，再累计前一完整雨季。

第一版雨季暂设11月至次年4月，须由实际季节曲线核对。`R_i,y`为雨季累计量相对固定长期基准的距平率；有足够连续逐月资料后可用SPI-6替代。两者不重复加权。降水用于水源压力和后续燃料背景，不预设雨越少火风险必然越大，巡护资源也不会改变降雨。

## 6. 预先规定的质量检查

1. **几何与覆盖**：区域不越出所选公园边界；检查空几何、自交、分区重叠和缺口。至少报告`sum_area`、`union_area`、`overlap_area=sum_area-union_area`、`gap_area=area(park-union)`和`outside_area=area(union-park)`；数值误差尺度单独注明。拓扑修复按报告图和明确的优先序分配重叠，逐区保存裁界/去重变化，不能以无重叠结果代替边界来源核验。
2. **面积核验**：每区保存源表面积与几何面积，报告相对差异`(geometry_area-source_area)/source_area`。未匹配或残差区域不计算无依据的误差比例。源表面积并非边界重建的独立真值，不能以总和一致代替空间核查。
3. **表格关联**：15统计单元各出现一次；`ENP3410`作为一个来源键。额外区明确无对应动物调查，不能生成伪实测零。物种明细保留年份、季节、估计方法、来源页和质量标记。
4. **数量核验**：候选6类的有数估计按区合计与原汇总一致；这是内部加总核查，不代表估计无误。源空白、未检出和调查外null不合并成一种缺失状态。
5. **源数据异常**：黑犀牛正文与表格矛盾、分区合计1,107与总计1,280冲突；Eland与跳羚等异常保留，主方案暂缓。不得利用空间分摊或归一化掩盖矛盾。
6. **图形对照**：检查分区与主盐沼、外边界、调查图编号及道路叠置的位置合理性；可视一致不等于官方精度认证。
