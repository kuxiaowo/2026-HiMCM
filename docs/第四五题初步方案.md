## 3. 第四题的核心问题

1. 人员或技术减少到什么程度，服务才开始下降？哪类资源成为瓶颈？
2. 地理通行和无人机作业条件改变后，原部署是否仍有效，应该怎样调整？
3. 关键假设改变是否会推翻“无人机节省人工”“需要前置响应”等建议？
4. 改变巡护安排时，月总人时相同是否仍能保持服务连续性？

敏感性分析需要计算，但不要求每一个情景都新增实测数据。现有数据足以重算资源情景；新增搜集主要用于支持参数范围、道路/设备条件和第三题的季节服务量。人为压力幅度与有资料支持的区间必须区分。

## 4. 建议计算设计

### 4.1 单因素变化：先检查资源，再检查假设

| 组别 | 第一轮设计 | 主要输出 | 数据和状态 |
|---|---|---|---|
| 可用保护人员 | H取基准的100%、90%、80%、70%、60%、50%、40%，必要时在转折附近加密 | 评分曲线、底线可行性、配置转移、预算余量 | 比例为压力测试设计，不是实际减员概率；120小时固定 |
| 无人机 | 6至0架对应U=240、200、160、120、80、40、0，其他作业条件固定 | 服务分、替代地面人工、无人机配套人工 | 这是按当前每架40机时/月换算；不能只改机器预算却忽略操作人员 |
| 地理通行 | 先整理已有20/30/40km/h，再补有依据的关键路段不可用情景 | 响应可达需求份额、地理上限、作业人时、区域缺口 | 路段和现场运行记录优先；道路限速不能直接等同实际平均作业速度 |
| 无人机替代假设 | 改变适用单元或增加明确的地面核查要求，测试续航/现场成本范围 | 地面/无人机投入结构、评分、必要人工 | 官方规格可支持设备边界，不证明本园实际使用型号或现场效能 |
| 服务要求 | 在服务标准确定后测试检查频次、区域底线及必要地面工作量 | 固定预算下评分、固定目标下人时、失效原因 | 变动的是管理要求，不能把放松标准后的高分解释为保护改善 |
| 价值与数据 | 整理AHP/熵权/CRITIC、数量区间、物种组合及网格尺度 | 分项完成率、部署排序、投入变化 | 历史区间不是2026总体置信区间；尺度变化也改变代表点与部分权重近似 |

H_0=2880保持基准响应方案时，H小于H_0必定不可行；满足H_0也不保证能够满足区域服务底线。不可行作为结果报告，不降低底线制造分数。

保持基准分所需的临界H应另求解，或接入第三题同条件的最小人时。不能仅将当前选定服务向量的5288.4人时宣布为所有同分方案的严格最低值。

### 4.2 两因素联合情景

首选人员H与机时U的二维组合，因为已有结果显示两类资源能够互相替代。输出热力图和可行性边界，识别人工充足时设备可替代、人工紧缺时设备重要的区域。

另一轮只保留少量联合压力：人工减少且作业耗时增加；第三题确定后的重点季节工作量增加且设备减少。不对所有参数做全组合枚举。

没有可信概率分布时，不进行带有发生概率或置信区间含义的随机模拟。离散情景范围只解释为已测试条件。

### 4.3 巡护安排：补齐原题明确提到的内容

当前月度LP只统计总工作量，不能区分同样点次集中在几天执行，还是均匀分散执行。仅改变月检查总数不等于分析巡护时间安排。

可在既有日间窗口内增加少量代表日期/时间窗口，对比均匀分配和集中安排，保持月总人时、机时与服务总量相同。检查每窗口服务容量、最长无检查间隔与分时缺口。时间窗和允许间隔要明确为规则或假设。

这是连续分期容量检查，不是详细人员排班MILP；不引入没有资格、飞行和响应依据的夜间能力。单人有效工时继续120，不重新扣节假日或假设高温折减。

### 4.4 每个情景比较“原安排”与“允许调整”

- 允许调整：在变化后的条件下重新求LP，得到可达最优服务。
- 原安排规则：保留基准空间分配比例/优先顺序，根据新预算缩放可变监测投入，并重新核算实际可提供的服务。共享响应人时单列，不能把总人工直接同比缩放后仍声称响应不变。
- 原安排规则不满足底线或新条件时，明确报告；不能将违反预算的原解与可行的新最优解直接比较。
- 报告重新配置能恢复多少服务、资源从哪些区移到哪些区。重优化表现好，不自动意味着原部署具有同样稳健性。

## 5. 比较和输出规则

共同输出：全园服务分P、两个对象分项服务、17区完成率/短板、人时用途和机时、响应范围、预算余量、硬约束可行性。第三题完成后再增加固定目标所需人时与规划人数，并报告最紧张时期。

固定权重、范围和标准的资源情景可以直接比较分数差。权重方法变化时，另外用共同基准权重评价各方案，并比较动物/生境分项及部署；不能把CRITIC的51.72与熵权57.26直接解释成真实保护下降。响应期限变化属于标准变化；3小时74.12分与2小时57.26分不能作为同标准效果提升。网格尺度结果是离散化敏感性，三个尺度不构成空间收敛证明。

优先使用变化量、分段曲线和转折位置。基准方案处在评分上限，微小扰动可能不改变分数；局部“敏感度为0”不能证明参数不重要。响应0/1门槛和方案切换还可能造成突变，不能只算一个平均弹性。

LP可辅助查看约束余量及局部边际信息，但只解释其对应的目标和约束附近变化。必须取第一阶段最大服务LP的边际信息；现有第二阶段最省人工解的边际值不代表服务分对预算的敏感性。数值结论仍以重新求解核对为主。[SciPy HiGHS官方说明](https://docs.scipy.org/doc/scipy/reference/optimize.linprog-highs.html)。

建议正文图表：人员/机时曲线、人员×机时热力图、关键情景17区缺口对照，以及巡护安排的分时对照。其余完整情景表放计算附件，不堆满正文。

## 6. 第五题：按“优点—证据—边界”评价

| 优点 | 当前证据 | 可以作出的论断 |
|---|---|---|
| 人机资源联合配置且人工不免费 | 独立人时/机时变量、无人机配套人工、设备停用对照 | 能量化所设协议下的技术替代与人工代价 |
| 显式地理和响应约束 | 有向道路、逐单元响应门槛、20/30/40km/h及前置点结果 | 能识别响应范围瓶颈，避免用监测掩盖不可响应 |
| 支持战略而非连续全覆盖 | 需求加权配置和区域底线，紧缺预算对照 | 同预算可比较部署，仍不代表每处连续有人巡护 |
| 计算可追溯 | 原始输入、参数表、结果、数据/脚本指纹和独立验证 | 可复核给定模型内的结果；不等于生态成效已验证 |
| 接口便于扩展 | 工作量可分期、必要地面人时可另列 | 第三题季节和水点工作可接入，不证明扩展已算完 |

局限按影响和适用边界说明：

| 局限/假设 | 可能影响 | 应怎样控制论断 |
|---|---|---|
| 2015动物、2021生态、2026道路混用 | 分布/优先级可能与当前不同 | 称条件性规划示范；年代差异不能由求解精度消除 |
| 重点物种和调查外数量缺失 | 所选目标不代表完整动物/生态保护 | 保留未知、专项缺口，不能以通用15%底线认证重点对象 |
| 火侧等暴露、权重方法与区内分布假设 | 需求和排序受代理/算法影响 | 使用共同尺度敏感性并说明尚需校准 |
| 六处候选驻点、权限和速度假设 | 可达范围和单位成本可能有误 | 现场日志可校准，候选地点不称现有巡护站 |
| 无人机与地面筛查等价假设 | 可能高估技术替代能力 | 检查技术适用性、地面核查需求；不外推到执法或消防 |
| 每次独立往返、代表点和连续点次 | 人时可能受路线串联影响；细片与实际次数不完全对应 | 称战略工时近似，另做尺度和执行次数复核 |
| 月度预算、日间窗口、稀疏事件 | 无法保证每班在岗、夜间保护或并发事件处置 | 不声称全年全天严格最低可行编制；巡护窗口分析也非完整排班 |
| 服务分与真实生态结果未建立校准关系 | 高分不能证明损失下降 | 明确是服务保障评分，不是动物存活率或生态认证 |

同分解可能不唯一，小幅参数变化导致投入位置变化时，先检查是否仍为近似同分且同样可行，避免将解的任意选择当成策略根本不稳定。算法最优只针对指定LP，不是现实全局最优。

## 7. 验证与后续实施顺序

验证分三层：数据与单位处理；预算、响应、适用性、底线及汇总一致；真实保护成效。前两层已有验证记录，第三层没有相应证据，不能合并声称“模型已全面验证”。

实施顺序：

1. 整理已有Q2情景为统一表，校准分数、人工用途和范围，不重跑全部数据处理。
2. 补人员/机时连续梯度、临界点和二维资源组合，复核单调性与可行性。
3. 搜集少量关键参数范围/作业依据，补技术替代、通行和服务标准敏感性；保留假设标签。
4. 第三题接口稳定后，接入季节与水点工作量和规划人数；不修改单人120小时假设。
5. 完成巡护安排代表窗口比较，再将第四题证据转成第五题优点、限制及适用范围。

本方案尚未证明全部结论对所有输入稳定，也未开展概率意义上的风险评估。论文最终结论应限定于实际完成并验证的情景范围。

## 8. 原第三题3.7内容的分析与评价安排

### 8.1 第四题：服务标准、清单缺失与参数校准

接入第三题两类LP及k_t、f_t、τ_t、W_t、η、U与月度人数接口，讨论服务强度、人员/技术、清单缺失和巡护安排对评分、配置及峰值人数的影响。有效工时120小时保持固定。

已有低中高标准的峰值51/57/72人、异常干旱运维压力下53/62/78人，以及水点工作量复制2/3倍后61/64人，统一在第四题作为规划情景解释，不称置信区间或真实水点数量。

优先校准当前人工水点清单及岗位归属、到场频次、现场耗时和大修记录、季节额外火险筛查定额、共用出行与人员资格。时间窗口和水点类型有资料，具体频次与耗时为假设；资料齐备后更新任务量并复算，不以放松标准后的高分解释保护改善。

### 8.2 第五题：范围限制与模型评价

地理范围：当前可响应可燃生境约6894.1km²，占模型可燃生境39.2%；重点火月份额外任务可履行275.76点次，另428.45点次未获所设响应保障。固定地理条件是人员结论的前提，单纯增加人工不能消除不可达缺口。

资料范围：水点仅覆盖17处历史BH样本，当前运行状态和完整清单未核实；动物、生境和道路资料年份不同。57/62是选定服务、可响应范围和样本水点的条件性规划人数，不是当前全园真实最低编制或完整生态成效认证。

执行范围：月度连续工作量、独立往返和人员池可重配置便于计算，也会影响实际岗位需求。26人同时在岗、最长中档水点作业6.39小时的基础筛查不能证明每驻点排班、任务资格、访问间隔或并发保障；服务分未与真实保护成效校准。

结合已有核验评价模型可追溯、可接入季节任务和反求人力的优点，同时区分数值核验、实际部署执行与真实生态成效。建议只覆盖已经计算和核验的情景，不声称所有参数下稳健。
