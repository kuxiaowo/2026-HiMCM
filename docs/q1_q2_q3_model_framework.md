更新：2026-10-05。第二题条件性规划已求解，第三题尚未估算。采用独立人时/机时LP；排除水源与降雨，不拟合投入—实际损失，不使用预测模型，不建立复杂轮班MILP。

| 题目 | 输入 | 输出及状态 |
|---|---|---|
| 第一题 | 历史数量、法规类别、生境、道路进入与火监测需求 | 对象价值、威胁代理、服务保护定义；已修改与第二题一致 |
| 第二题 | 服务标准、候选驻点、作业时间、人员/机时预算 | 17区配置及所选已知对象服务分，基准和紧缺/地理情景已算 |
| 第三题 | 同一标准、设备条件、时间需求和服务目标 | 每期最高服务与最小人时，换算规划人数；尚未求解 |

父区i为17统计/生态区，检查单元j为格网与区域相交连通片代表点；x_j是地面监测人时，h_j是机时，s_j是规定检查的完成比例。r_j为日间固定驻点的响应可达性0/1。w_j按测得动物/进入分项与等暴露可燃生境分项按15共同有数据区的熵权0.645551/0.354449汇总且合计1。部分重点对象仍未知，不能以六类动物/燃料面积替代全部生态价值。

C_j按固定单位面积服务标准确定，a_j为完整地面检查人时，b_j为完整无人机检查机时，o_j为该次无人机配套人时，γ_j=o_j/b_j。这些来自路线、速度、队伍人数和观察协议，不是实际减损拟合；未知地理条件/日志保留限制。

第二题max P=100Σw_j s_j，约束C_j s_j≤x_j/a_j+h_j/b_j、0≤s_j≤r_j、Σx_j+Σγ_jh_j+H_0≤H、Σh_j≤U。每区可响应部分的15%通用服务底线及无人机适用性另约束。H_0为共享驻点响应人时。区域汇总人工包括x及γh，机时另列，响应不按区重复扣。

第三题沿用同一约束和作业参数，加入P_t≥η，去掉固定人员预算作为目标限制，min H_req,t=Σx_j,t+Σγ_j,t h_j,t+H_0,t；N_t=ceil(H_req,t/q_t)。全年常设人数初估取最紧张期，不按月相加，并另检查基本同时在岗。目标超过同一地理条件上限时直接报告不可达，不能用任意加人或降低标准掩盖。

历史火单月样例只作QA检查，主模型火侧等暴露假设必须标明。P是所选对象的规划监测服务分，不是真实保护成功率，也不认证重点对象资料不全时全园达标。
