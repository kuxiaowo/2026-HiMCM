父区i为17统计/生态区，检查单元j为格网与区域相交连通片代表点；x_j是地面监测人时，h_j是机时，s_j是规定检查的完成比例。r_j为日间固定驻点的响应可达性0/1。w_j按测得动物/进入分项与等暴露可燃生境分项按15共同有数据区的熵权0.645551/0.354449汇总且合计1。部分重点对象仍未知，不能以六类动物/燃料面积替代全部生态价值。

C_j按固定单位面积服务标准确定，a_j为完整地面检查人时，b_j为完整无人机检查机时，o_j为该次无人机配套人时，γ_j=o_j/b_j。这些来自路线、速度、队伍人数和观察协议，不是实际减损拟合；未知地理条件/日志保留限制。

第二题max P=100Σw_j s_j，约束C_j s_j≤x_j/a_j+h_j/b_j、0≤s_j≤r_j、Σx_j+Σγ_jh_j+H_0≤H、Σh_j≤U。每区可响应部分的15%通用服务底线及无人机适用性另约束。H_0为共享驻点响应人时。区域汇总人工包括x及γh，机时另列，响应不按区重复扣。

第三题沿用基准监测x/h/s、成本γ_j和区域底线，加入P_t≥η=P_2*，去掉固定人员预算作为逆向求解的约束。新增y_j,t/v_j,t分别为额外火险检查人时/机时，W_t为地面水点运维人时，min H_req,t=Σ(x+γ_jh+y+γ_jv)+H_0+W_t；基准与火险共用240机时上限。N_t=ceil(H_req,t/120)，有效工时按用户决定固定，不扣节假日。全年固定人数取月度峰值，不按月相加；基本人员数检查不等于详细排班验证。固定59人分析另加入H_req,t≤7080并最大化基准服务分。目标超过地理上限直接报告不可达，额外火险不可响应范围单列未保障。
