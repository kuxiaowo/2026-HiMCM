**第五部分：模型优势、局限与适用范围**

版本：2026-10-06。参照[第二题框架](../paper/question2_framework.md)的标题组织方式，承接[第三题框架](../paper/question3_framework.md)和[第四题框架](../paper/question4_framework.md)，构建第五题的一、二、三级标题与逐节论证路线。本轮完成正式写作框架，不新增模型自评分，不扩写第六题迁移案例或整篇论文目录。

**本部分回答的问题。**前述模型能够支持哪些规划决策；这些能力有哪些数学结构和计算证据；哪些资料、假设或执行简化会限制结论；正式应用前先补什么。题目要求讨论优势与局限，不要求再建立一套AHP、熵权或综合打分系统评价模型自身。

**完整逻辑链，按三步写作。**

1. **用结构与结果说明优势。**每项优势都连接一处模型设计和一项已有证据，说明它对保护规划有什么帮助。
2. **说明简化怎样影响结论。**从数据、服务假设、执行时间及实际保护成效四方面说明局限，不只列“数据有限、模型简化”。
3. **划定适用条件并安排改进。**明确现在能使用哪些结果、不能据此判断什么，再按影响程度提出数据校准和执行验证顺序。

主线是“能力—证据—边界—改进”。第四题尚待计算的结果不能作为第五题已经确认的优势依据。

# 5 模型优势、局限与适用范围

## 5.1 模型优势及其依据

### 5.1.1 人机协同核算与显式地理响应约束

先说明具体能力：模型将地面检查、无人机飞行、配套人工和共享响应分别核算，使设备节省人工的条件可以计算；同时以有向路网、道路外接近和响应期限限制有效服务，不把能观察到等同于能到场响应。

证据引用第二题的预算和容量约束、无人机减半/停用结果，以及不同道路速度下的响应范围。基准设备停用仍达57.26分但人工增加，体现的是给定筛查协议下的资源替代；道路速度改变服务上限，体现地理条件对规划的作用。

据此可以写：模型能区分监测与响应，量化所设工作方式下的人机替代代价并识别响应瓶颈。不能据此写无人机可替代执法、消防或水点维护，也不能将六处候选营地/入口称为已核实巡护站。

**论证顺序：**结构如何计入人工和地理 → 计算体现什么差别 → 这对资源决策有什么帮助 → 限定为所设协议和候选地点。

### 5.1.2 战略部署与季节人员需求的统一分析

说明模型在资源紧缺时综合需求、作业成本和区域底线配置，不要求完全覆盖；第三题复用相同服务定义，将额外火险与水点工作量计入统一人员预算，分别评估固定人数服务和固定目标所需人工。

已有同预算紧缺比较：优化45.77分，需求比例38.24分，面积均衡31.30分。它支持“在这些相同预算、权重和约束下，优化配置提高所定义服务分”，不支持所有现实策略均被击败。

第三题中档峰值57人，所设异常干旱运维压力下62人，说明同一目标可以转化为季节工作量和条件性岗位需求。采用月度峰值而非年度平均，可以避免平均人工充足掩盖重点月份不足。

**论证顺序：**部署任务与时间任务共用约束 → 紧缺对照和季节结果 → 可用于优先级和人员余量规划 → 人数仅针对选定任务、可响应范围和历史水点样本。

### 5.1.3 管理含义清晰与计算可复核性

说明变量有明确单位：人工是人时、无人机是机时、服务是规定点次完成率，新增任务先转为工作量再换算人数。原始来源、参数假设、结果、分区汇总和独立核验均保存，可检查计算链。

证据引用第二题核验，以及第三题逐点容量、必要任务、人机预算、评分、取整、分区汇总和独立核验。线性规划可求给定模型内的最优解，逆向求解可以解释目标和人员需求的关系。

明确三个验证层次：输入与单位一致性、模型约束与数值结果一致性、现实执行及保护成效。现有检查支持前两层，不能把数值残差很小写成已通过实际生态验证。第二题固定服务向量的人工最小化与第三题允许同分向量重配的人工最小化，也应准确区分。

**论证顺序：**变量和数据链可解释 → 保存与独立核验可追溯 → 给定模型内可复算 → 现实有效性仍需外部资料。

## 5.2 模型局限及其影响

### 5.2.1 历史资料、对象缺失与空间近似

集中讨论资料范围：动物调查、生境底图和道路资料年份不同；动物指标只覆盖所选历史调查对象，重点物种、珍稀植物与调查外数量仍缺失；水点运维仅基于17处历史BH样本，不是已核实的当前完整台账。

解释影响：需求权重和空间重点可能与当前情况不同；未进入评价的对象不能被较高总分代表；台账缺失可能低估完整工作量，新点位路线不同又不能靠简单倍增精确推算。

空间简化包括区内动物均匀分布、格网连通片代表点和可燃生境等火暴露代理。599个计算单元提高了路线与响应计算的分辨率，但不会把15个动物调查区变成599条实测动物数据。5/10/15 km差异说明近似影响，不证明连续空间覆盖。

**论证顺序：**具体资料/假设 → 会影响哪一输入或需求 → 哪些结论必须限缩 → 对应数据校准。引用第四题已经完成的权重、格网和清单工作量测试；未完成测试不写成已验证稳定。

### 5.2.2 服务标准、赋权与技术替代假设

列出仍需校准的管理规则：每100 km²每月8次基准检查、2小时日间响应、可响应部分15%区域底线，以及新增火险频次、水点访问间隔和现场耗时。季节窗口及点位类型有资料，具体频次和耗时多为团队假设，不能混写成公园现行制度。

赋权限制分层说明：动物保护类别AHP反映团队判断；熵权反映当前数据的相对差异，不能代表真实生态损失占比；可燃生境等暴露不等于经校准的有害火灾概率。火险检查不包括扑救、防火带清理或计划燃烧。

技术方面，只在所设合格筛查协议及适用地形中假设地面与无人机可替代；尚未由本园作业日志证明两者的检出能力等价。若实际需要更多地面核查或技术适用范围较小，人工需求可能增加，但不能在未计算前给出幅度。

**论证顺序：**假设承担什么作用 → 改变后会影响评分分母、工作量或替代关系 → 通过哪些第四题情景检验 → 仍需要什么现场证据。低中高服务方案是管理标准情景，不是统计误差区间。

### 5.2.3 月度工时、独立往返与执行安排简化

说明月度LP允许连续点次和人工池调配，单人有效工时按约定固定120小时。工作量除以120再向上取整，证明的是该月总预算足够，不证明每人资格、每驻点同时人数、整数派遣及任务日期均可执行。

现行独立往返未优化串点路线，不同任务不抵扣共用出行，可能高估某些可合并任务的出行人工；相反，遗漏故障、大修、驻点转移、夜间或并发响应等任务又可能低估现实需求。两类影响方向不同，不能把最终57/62人笼统称为现实需求的上界或下界。

规定日间窗口和稀疏事件假设限制夜间及同时多事件保护。已有26人同时工作数量筛查和最长单次水点作业时间检查可排除部分明显冲突，但不能代替详细执行核验。第四题代表时间窗口分析完成后可补充时间连续性证据，仍不等于完整轮班模型。

**论证顺序：**月度连续近似降低计算复杂度 → 总量与具体执行的差别 → 可能高估及低估的工作来源 → 将人数称为条件性规划建议。

### 5.2.4 服务评分与实际保护成效的差距

明确服务分衡量需求加权的规定监测完成能力，响应门槛衡量在给定路线和期限下的可到场条件。它们不能直接换算为动物存活率、偷猎减少比例、生态损失降低或全园保护认证。

第三题沿用 \(\eta=P_2^*\)可以保持比较一致，并避免另指定一个任意分数，但“维持基准水平”是管理选择，不能证明原检查频次和响应期限具有生态充分性。57.26分也不是“57.26%的动物受到保护”。

平均分还可能遮盖未调查对象、不可响应区域和专项任务缺口。因此同时保留对象分项、区域底线、未响应任务和水点样本范围，不能让总分抵消硬性任务未完成。模型优化精度无法弥补评分与生态结果之间缺乏校准关系。

**论证顺序：**评分实际测量什么 → 尚未测量什么 → 哪些结果不能据此声称 → 需要作业记录及独立成效证据建立联系。

## 5.3 适用条件与改进方向

### 5.3.1 适用任务与结论边界

说明当前适用于数据受限条件下的战略资源比较、响应瓶颈识别、所设监测/运维任务的工作量核算和季节岗位需求估计。使用者需要认可所设服务协议，核验候选驻点与道路权限，并明确不同任务是否由同一人员池承担。

条件不满足时应重新标定输入：岗位分离时不能直接共享余量；候选道路不可用时应重算路径与可达性；目标高于新的地理上限时应先调整响应方案。它不直接提供执法效果预测、全天值班表、真实最低编制或完整生态认证。

结论只覆盖实际完成并核验的情景。少数结果不等于所有扰动下稳健；同分解地图变化也不一定表示策略失效。公平比较要求共同预算、权重、范围和标准，改变其中一项要说明。

**本节输出：**适用任务、必要前提和超出模型能力的决策范围。

### 5.3.2 关键数据与参数的优先校准

按对规划结论的直接影响排列改进顺序，而不是笼统要求收集所有数据：

|优先项|需取得的证据|用来改进什么|
|---|---|---|
|现行任务和岗位边界|完整人工水点清单、运行状态、维护部门、岗位资格|工作范围、共享人员预算和水点工作量|
|实际响应和作业成本|驻点、通行权限、路线日志、现场耗时、可飞行日|可达范围、人工/机时成本及时间容量|
|服务要求与筛查能力|检查记录、访问日期、地面/无人机合格筛查及核查记录|频次、访问间隔、技术替代和额外工作|
|对象需求及保护成效|更新的动物/生境/威胁资料和独立成效记录|需求重点、未知对象及服务—成效联系|

这些是后续校准资料，不假装当前已经取得。先修正范围与成本，再解释人员数；若要声称真正的保护改善，还必须取得相应独立成效证据。单人120小时按用户约定固定，不列为本轮新增敏感性变量。

**本节输出：**能直接交给数据搜集与模型校准工作的优先清单。

### 5.3.3 分阶段改进与后续分析接口

第一阶段补台账、通行和作业成本，保持现有LP结构；第二阶段补代表时间窗口及具体任务执行检查，再根据实际需要处理资格、路线合并或整数派遣；第三阶段在有真实观测资料后研究服务与保护成效的关系。改进按决策需求选择，不一次扩展成复杂预测与排班系统。

为第六题只给结构接口：需求定义、作业成本、服务容量、资源约束、响应条件及固定目标反求人力可以作为待检验的迁移框架；当地威胁、数据、技术条件和服务标准需要重新校准。本节不提前选择另外两个公园，也不把可写接口当作已完成跨园实算。

**本节输出：**分阶段改进路径及对后续迁移分析的接口说明。
