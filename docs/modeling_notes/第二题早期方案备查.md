# 第二题：独立配置人时与机时的精简方案

更新：2026-10-05。本方案落实用户最新讨论，作为第二题和第三题接口的当前版本。资源优化尚未执行，服务标准、作业时间及基本响应条件尚待填齐；水点台账及水源专项工时已从当前方案删除。此前共用一个完成比例、固定消耗 a_i s_i 与 b_i s_i 的模型不能优化两类资源的替代组合，予以替换；复杂轮班MILP不是当前实施要求。

## 1. 价值权重与保护需求权重

AHP可用于少量物种保护类别或价值指标的权重 q_s，不能凭AHP产生区域动物数量。优先对法规保护类别比较，避免对17区作136次成对比较；也避免逐个物种增加大量判断。法规类别提供重要性依据，不直接给出唯一数值权重。判断矩阵、理由、一致性检验和敏感性需记录；常用CR≤0.10作为检查规则，未通过应检查判断，不能为通过检验随意修改结论。

动物区域价值可沿用已有基线：V_i^animal = Σ_s q_s n_is / Σ_j n_js，其中同一物种分母限于一致的调查范围。每种动物按其园内份额贡献，避免数量大的物种直接压倒其他物种。n_is是历史调查量，不称当前实测；未调查与未知不能填0。AHP尚未实施，现有1/2/3类别权重仍是基线假设，不能称AHP结果。

V_i是价值，w_i是综合价值、威胁及保护对象后归一化的需求权重，两者不能混同。AHP也可确定少量威胁间的判断权重，但威胁强度本身来自道路进入时间、历史火暴露等客观代理。缺失的黑犀牛、植物和盐沼对象继续保留独立最低服务要求，不靠六类动物权重替代。

## 2. 服务标准的用途

服务标准是管理目标，不另加到生态价值指标中。它回答某时期需要提供什么服务，随后将有限资源换算为完成率。

- C_i：区域在该期要求完成的可替代监测服务数量。
- H_response：固定驻点、固定预留响应方案占用的人时；驻点服务多个区只计一次。
- 必要底线：重点对象最低完成率、不可替代现场检查、可达性及响应期限。

第一版固定路线、目标点组和检查协议。一单位可替代服务定义为完成一轮既定重点点位组的合格观测，或一条既定监测线路的合格检查。目标、时段和合格条件相同才可在地面与无人机之间换算；重复拍同一点不增加独立服务。无人机照片不能算泵设备检修或现场执法。不同用途无法确认等价时，保留单独标准，不任意折算成同一种服务。

用少量全园共享频次、队伍人数和停留时间，保留区域差异来自路线及目标点数。任何每月检查几次、响应30/60分钟、全园80分、重点0.90均为待验证规划示例，不是公园管理制度。频次及目标不能由当前预算反推，否则会降低标准制造达标。

## 3. 作业时间与可参考数据

地面一轮用时 t_i^g = 路线长度/有效速度 + 检查停留 + 必要准备。p名队员参与则占用 p t_i^g 人时。无人机一轮机时 t_i^u 使用空中往返距离、有效飞行速度、观察时间及适用的续航限制；地面路网距离不能直接当飞行距离。换电、准备、影像审核等人工开销进入配套人时，不能全部冒充飞行时间。

若两种方式分别独立完成全部C_i轮服务，参考时间可写 a_i^ref = C_i p t_i^g，b_i^ref = C_i t_i^u。两者表示纯地面和纯无人机方案的参考消耗，不要求联合方案同时投入这两个总量；且不含无人机无法完成的地面任务。

现有道路可提供长度和网络结构；进入点、驻点接入、具体检查路线仍未完成。30km/h为现有初版路速假设，20/40用于敏感性，并非本园实测。SMART说明巡护距离和起止时间可以记录及分析，但本项目尚未取得本园记录。设备官方续航可限制飞行计划，却不等于现场有效观察时间，也不证明本园使用该型号。

服务率 c_i^g = 1/(p t_i^g)，单位轮/人时；c_i^u = 1/t_i^u，单位轮/机时。它们来自明确作业协议和时间预算，不是资源投入对动物损失的拟合效能。

## 4. 资源组合优化：线性规划

变量 x_i为可替代地面监测人时，h_i为无人机监测机时，s_i为该期监测标准完成率。路线和基本响应方案固定，采用连续工时的战略规划近似。

目标：max Σ_i w_i s_i。

约束：

1. C_i s_i ≤ c_i^g x_i + c_i^u h_i，0≤s_i≤1。
2. Σ_i x_i + γ Σ_i h_i + H_0 ≤ H。
3. Σ_i h_i ≤ U；无法适用无人机的区域设h_i=0，必要时另限区域可替代服务上限。
4. 重点对象最低服务、地面不可替代工作和固定响应可达性需通过检查。

H是该期可用保护人时，U是可用机时，H_0=H_response+其他明确必需人时（不含水源专项工时），按真实作业去重。γ表示每机时配套的操作、准备及审核人时，采用全园共享口径；如另计固定准备人时，不能再重复包含于γ。无人机飞行占用人员，不能当免费机器。

优化器决定x_i、h_i的组合，不规定二者比例；可出现部分区偏向无人机、部分区偏向地面，或资源约束下的混合。最佳组合必须以可替代工作和作业时间为依据，不能由w_i单独自动生成。局部组合可能不唯一，应报告同分方案/轻微参数扰动结果。

不假定所有观测都同样有效：只对符合预先协议且有相应响应保障的服务计分。重点点位缺少响应条件需单列短板；不能用区中心可达证明全区可达。火发现和偷猎核查若不能共享协议，不在同一个计数中随意相加，可保留少量用途索引的同类约束，仍属LP。

本模型先用scipy.optimize.linprog(method='highs')求解；不预先规定人员与无人机比例，不拟合实际减损函数。频次的非整数结果是规划工时近似，落地需要按实际次数整理并复核预算，不能称精确排班。若硬性底线在预算内无解，报告缺口，不暗中降低要求。

全园100Σw_i s_i为需求加权的监测服务完成分，只在基本响应与地面底线均满足、评价范围完整时可作为本方案的保护服务评分；不是实际生态保护成功率。

## 5. 删除具体水源数据与专项工作

按最新精简讨论，不收集水点坐标、地下水、供水类型和运行台账，不建水源巡检路线，也不计H_water。基本响应保留，驻点到目标的道路/道路外与调度时间仍需核验，共享预留人时只计一次。

删除数据意味着当前模型不评价实际水源可用性、设施运行或水源保障效果。自然干旱仍可讨论，但不能用降雨替代这些结论。

## 6. 降水保留为气候压力，不自动增加人时

GPCC五年样例已提取17区月序列；完整50年未拼接、SPI未计算。雨季SPI与δ=clip(-SPI/2,0,1)用于表示降水异常和0—1压力，雨季窗口仍需核验。

SPI与δ不直接判断水源断供、不自动增加巡查频次或人员、不改变动物价值，也不直接乘入火风险。取消此前H_water乘(1+λδ)规则及λ参数。当前主要作气候背景和时间/情景解释；若以后建立少雨与某种可干预工作量的可信关系，再另行设计资源接口。

同一降水因子统一乘所有w后归一化会抵消；区域划分不提高原GPCC分辨率，不制造分区独立实测。50年降水不提供50年真实人员或保护部署。

## 7. 第三题接口与未完成事项

第三题保持同一服务及响应标准，固定机时上限，允许重新优化x、h，最小化H_req=Σx+γΣh+H_0。在各时期目标及重点底线约束下得到规划人时，再除以该期单人有效保护工时向上取整。全年常设人数不按月相加，而要满足最紧张时期；已在有效工时扣除的休假/准备等损耗不再扣第二次。

当前称规划人数估算，不称严格最低可行编制；不建立复杂轮班MILP，不预测动物数量。固定驻点方案须另检查基本同时在岗需求，月均工时不能证明持续值守可行。

详细时间分析和人员反求见[第三题精简方案](第三题精简方案.md)。
