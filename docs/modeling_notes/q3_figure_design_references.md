# 第三题图表设计来源与原创绘制记录

更新：2026-10-06。本次只借鉴公开论文的图表组织方式，图形与数值均由本项目保存的输入和解原创绘制。

## 表达参考

1. [Deploying PAWS: Field Optimization of the Protection Assistant for Wildlife Security](https://doi.org/10.1609/aaai.v30i2.19070)，2016。公开PDF第4页Figure 5采用输入、分析、模型、策略的模块箭头；第三题图3-1借鉴其明确标出数据到输出的关系，按本项目两类LP重新设计。
2. [Improving Community-Participated Patrol for Anti-Poaching](https://arxiv.org/pdf/2412.10799)，2025。公开预印本第7页Figure 3并列空间图与部署、预算结果；图3-2将历史点位与路线成本并列，图3-4将相同峰值月的人工需求与服务结果并列。

未使用这些论文的现成图片、数值或博弈模型。窗口与水点来源另见正文参考文献，规划频次与耗时明确列为团队假设。

## 正文图表的论证作用

|编号|图表内容|正文中的作用|
|---|---|---|
|图3-1|固定基线、附加任务、共同约束、两类模型|说明固定人数与固定目标分别求什么|
|图3-2|17处历史钻井地图与单点月运维人时堆叠|把点位、路线、现场和准备时间连接起来；成本取中档旱季|
|图3-3|12个月四类人时堆叠与人数曲线|解释季节峰值及固定人数取月度最大值|
|图3-4|常规季节、异常干旱的峰值人工与固定59人评分|解释预算超过7080时的服务缺口与追加3人|
|表3-1|继承输入及月度参数|集中交代核算口径|
|表3-2|四组月份的水点与火险规则|区分资料支持的窗口与假设频次|
|表3-3|五组决策变量|区分自由投入、预定水点人时与换算人数|
|表3-4|四组月份的人时、人数、机时与服务分|给出可核对的主要结果|

人时各分项相加，机时单列；服务评分与人数使用不同坐标轴。图3-4服务轴从52分起，图内与图注均明示。地图只显示已有研究公开的历史水点和规划驻点，未使用敏感动物轨迹，未绘制虚构的维护路线。地图轮廓简化仅用于展示，比例尺使用模型UTM坐标，17处样本合计422.34旱季运维人时可由分项重新核对。
