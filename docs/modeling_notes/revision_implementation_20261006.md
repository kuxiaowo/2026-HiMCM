## 1. 改造范围与数据判断

论文主线改为多物种保护。管理目标面向野生动物，但动物数量量化仍限于2015年调查中的象、长颈鹿、平原斑马、剑羚、蓝角马和鸵鸟六类对象。数量份额用于衡量区域保护责任，不是偷猎概率，也不代表2026年所有动物的分布。

犀牛偷猎继续作为定性挑战。黑犀牛源报告的分区数量合计1107与汇总1280冲突，尚无依据选定改值，因此没有把该表加入主模型。六类主输入的内部加总一致，也不能消除原调查方法和扩展估计中的质量疑点。未纳入物种保持未知，不能因无输入而赋予零生态价值。

本轮已取得并使用NPS2022年黄石狼群历史活动范围。奇特旺虎数据仅取得部分公开预览，没有将预览冒充完整数据。资料核查、失败请求与证据范围见[实施前可行性核查](revision_data_feasibility_20261006.md)。

## 4. 跨公园与面积溯源

奇特旺所用公开多边形的测地面积为1213.002628平方千米，与源GIS属性1213.002660一致；UTM45N面积为1214.063465。投影影响约0.087%，不足以解释与官方952.63之间约27%的差异。官方2020年GIS报告第17页也合计952.63。问题已定位到源几何与报告面积口径尚未闭合，但未确认具体错误边段；没有缩放几何来凑面积。第六题结果继续标为发布多边形的条件试算。

黄石取得10份2022年狼群95%最小凸多边形文件，含9种独特几何；合并重叠及重复后裁园，合计4093.87平方千米，并按已有单元陆地份额调整交叠。历史范围与陆域份额混合构造独立权重情景。每套新权重以原Y0方案在该权重下的评分为目标，再求最少人工。

两类权重各占一半时，61个单元服务改变，人工1474.68人时，而原面积权重评分从16.85%降至15.12%。这是优先事项取舍，不是生态效果提升。历史活动范围不代表当前密度或偷猎风险；独立结果没有覆盖原第六题面积基准。
