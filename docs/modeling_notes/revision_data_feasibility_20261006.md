# 论文修改的数据可行性与冲突溯源

本文件记录正式实施前的资料核查状态。多物种改造随后已完成，当前求解、论文及核验结果见[实施报告](revision_implementation_20261006.md)；文中“尚未修改”等句保留其当时语境。

核查日期：2026-10-06。当前项目目录：`D:/Python/programs/GitHub/2026-HiMCM`。

本轮核查原始PDF、既有转录表、地理处理脚本和新取得的公开资料，独立重算合计与面积。这里报告的是修改条件，尚未把新资料加入正式论文或替换第二至六题的模型结果。

## 1. 可以先下的判断

修改可行，但应分三类推进。

- **已有资料足够：**调整摘要与过渡、删去重复解释、修正字号与分页、补充已有网格敏感性、展示资源紧张情景，以及把第二题的二阶段求解改为“保持最优分数后全局最小人时”。这些修改无需等待新调查。
- **可以做有明确范围的增强：**黄石已有可读取的历史狼群领地GIS和季节道路资料；埃托沙黑犀牛可以讨论历史区级分布情景，但冲突表不能直接认证为可靠数量底表。任何新权重都应重新求解、另列情景，不能沿用旧分数。
- **目前不能做实证校准：**当前黑犀牛完整分布、埃托沙地面/无人机检查等效性、完整现行水点运维台账、任务实测工时及生态损失响应关系仍缺可用数据。奇特旺的法定报告面积与公开几何也未统一。

缺少校准资料，不妨碍做诚实的规划模型；但不支持把规划假设改称实测参数，或把服务完成率改称生态保护效果。

## 2. 黑犀牛：矛盾在原报告内，真实改值尚不能确定

来源为Kilian的2015年航空调查，原PDF第9页表6。本轮重新提取原PDF并目视检查原页，随后核对现有JSON，三者在以下数值上相符。

| 核查字段 | 有数分区合计 | 表6总计 | 表2汇总 |
|---|---:|---:|---:|
| 目击数 | 317 | 317 | 317 |
| 数量估计 | 1107 | 1280 | 1280 |
| 方差 | 7166.7 | 7166.7 | 7166.7 |

数量差173，约为印出总计的13.52%，不能用普通整数取整解释。第20页趋势图也写2015年1280，但它仍属于同一报告，不能作为独立调查核验。第3页1.6称不呈现黑犀牛数据，表格及分布、趋势图却实际存在，说明报告还有编辑一致性问题。

**已经确定：**不是本地OCR或JSON转录把1107变成1280；矛盾来自所取得的原报告。当前六类主物种并未使用黑犀牛冲突数量，因此不能把这个差额当成现有57.26%结果的计算错误。

**尚不能确定：**是总计引用了其他计算、某个分区估计写错，还是报告采用了没有交代清楚的不同汇总口径。报告使用Jolly方法2，原始航线观测和Excel不在当前公开资料中；不能根据目击数除搜索比例就声称完整重算了该估计。也不能把173任意补到某个分区。

可行处理有两层。正式底表继续保留原值和质量标记；若需要检验黑犀牛是否改变部署，可把原分区值作为**有争议的历史空间情景**，另测物种权重、未检出及分区不确定性。使用分区和归一化，只是在定义情景中的份额，不能宣称已经修复真实总量。

针对较新数据，本轮取得2019年原始研究《Mesoscale movement and recursion behaviors of Namibian black rhinos》。它使用埃托沙39只个体的轨迹，数据可得性声明明确说定位数据不公开，仅可能向作者提出合理请求。它能支撑运动与栖息地讨论，不能提供全园完整密度矩阵；本轮没有向作者或管理部门联系索取资料。

## 4. 奇特旺：不是本地投影导致27%的差异

本轮直接重算原始WDPCA、OSM及ICIMOD文件；当前正式试验使用WDPCA site805，并未误用Chitwan行政区。

| 来源/计算口径 | 公园面积，km² | 证据意义 |
|---|---:|---|
| DNPWC现行公园介绍 | 952.63 | 主管部门公布的公园面积；缓冲区另列729.37。 |
| 本轮取得的DNPWC GIS数据库报告 | 952.63 | PDF第17页四个地区的公园面积合计也为952.63。 |
| WDPCA源属性`rep_area` | 932.00 | 与现行官方公布数不同，不能把数据库发布月当该字段的实际更新日期。 |
| WDPCA源属性`gis_area` | 1213.00265952 | 发布方自己已经记录这个较大的几何面积。 |
| 同一WDPCA多边形，WGS84测地面积 | 1213.00262806 | 与发布GIS面积相差约0.00003146 km²。 |
| 同一多边形，UTM45N投影面积 | 1214.06346461 | 与测地面积约差1.061 km²，即约0.087%；不足以解释大差异。 |
| OSM国家公园多边形，UTM45N | 1208.57844241 | 更换为OSM也不会使面积变为952.63。 |
| ICIMOD国家公园多边形，UTM45N | 1213.72296155 | 原几何有自相交；规范修复后面积基本不变。 |

论文现有27.44%来自UTM面积与952.63的比较；测地面积对应的差异约27.33%。两个口径都显示同一个大问题。

进一步排除了两个常见解释。WDPCA与修复后的ICIMOD公园几何对称差只有约0.856 km²，说明它们高度相似，不能视为两个独立校准证明。WDPCA与ICIMOD缓冲区的重叠约0.479 km²，也不支持“整块缓冲区混入造成约260 km²差异”的说法；该结论限于所比较的这套公开缓冲区文件。

**错误层级已定位：**公开源数据的报告面积、几何面积与官方报告口径未闭合。**哪一个应修正仍未知：**面积不一致本身不能证明某一段边界必然画错，也不能证明952.63是现代GIS意义下的准确测地面积。需要与法定图件对应的矢量或明确的口径解释，才能定位“多出来的是哪一片”。不能缩放多边形凑面积。

NTNC公开目录确有来自DNPWC的公园边界图层及GeoJSON、Shapefile下载入口，但当前访问有证书/连接问题，没有取得该文件。目录范围与现有公园几何很接近，即使取得也必须重新验算，不能预先认定它会解决差异。

本轮取得的47页官方GIS报告封面写Bhadra24,2077，并引用DNPWC/MoFSC2020，已按2020资料保存；它不是另一个在旧出版物目录中列出的“CNP基础设施2022”报告。来源年份不混用。

## 5. 找到的新资料能支持什么

### 5.1 更近的埃托沙总量可以找到，分区矩阵仍未取得

本轮下载IUCN/TRAFFIC的2025年CoP20提案分析，第93页转载政府估计，列埃托沙象3266头。CITES提案的可检索注释将相关调查标为2023年；CITES原PDF本轮下载仍返回403。

因此，“完全没有较新数据”应改为“取得较新的公开总量及调查线索，尚未取得可替换2015年15分区表的原报告/矩阵”。2015年的2911与新资料的3266属于不同时间与来源，不能仅因不同就判定数据冲突，也不能按统一增长率放大旧分区值，冒充新空间分布。

### 5.2 黄石生态与季节资料已实际取得，可进入后续准备

已下载NPS官方1995—2022狼群领地压缩包，读取其中2022年10个多边形，全部有效；源坐标系EPSG:26912，已在本轮独立目录转换为WGS84 GeoJSON。它们是历史95%最小凸多边形，不是狼密度、完整当前分布或正式保护优先级。

同时下载2025年《Yellowstone Wolf, Cougar, and Elk Project Annual Report》及2026年道路开放网页。后者明确普通车辆多数道路季节关闭，并给分路段的计划开放日期；天气可能改变日期，游客通行规则也不自动等于管理人员应急通行权限。

可据此设计“本地历史动物活动范围责任”与“季节路网”两个独立迁移情景。它们有资料基础，仍须定义管理目标和服务任务，重新求解；不能把2022年几何称作2025或2026的精确活动范围。

### 5.3 奇特旺老虎数据：公开字段可核查，完整文件尚未取得

找到Prasai等的Chitwan—Parsa虎占域研究及Dryad数据集`10.5061/dryad.7h44j1057`。目录列出`Data.csv`及其他CSV。公开API给主CSV大小783106字节和SHA-256；公开预览有经纬度、重复调查、栖息地、物种记录以及2×2/10×10调查网格字段。

本轮保存了**48条完整预览记录**，另有一条在预览末尾被截断，未补齐；这些记录明确标记为预览，不进入模型。普通下载返回403，API下载返回401，完整CSV未取得。不能把“目录可见”写成“完整数据已下载”。

还有一个待核问题：Dryad目录把调查写为2020年12月—2021年2月，论文的可检索摘要（含PubMed索引）写2021年12月—2022年2月；预览日期没有年份，尚不能决定哪个正确。PubMed本地请求取得的是浏览器检查页，没有将其当成原文。数据在2026年发布也不表示2026年采样。

这条路径能支持后续历史出现/占域情景的准备，但完整文件、年份和调查努力处理仍待确认。出现或痕迹次数不能直接当种群数量；占域概率也不等于偷猎风险。研究范围包括Parsa与邻近森林，需要处理范围和边界，不能把全部记录归给奇特旺。

## 7. 建议的后续顺序

**本轮范围调整：**按用户提出的多物种方向，主线采用野生动物共同面对的偷猎、非法进入及有害野火和生境损害等保护挑战，动物量化继续使用现有六类调查对象：非洲草原象、长颈鹿、平原斑马、南非剑羚、蓝角马和鸵鸟。原题第一项要求识别并排序主要保护挑战，注意风险可随物种、栖息地、地点或威胁类型变化，没有要求建立犀牛专项模型。共同的规划结构不意味着各物种风险相同；数量及分布用于构造保护责任，不解释为实测偷猎概率。

“面向野生动物的多物种保护”是管理目标，“六类有调查记录的动物”是当前量化范围，两者必须分别表述。不把2015年历史调查说成当前分布，不把未纳入的物种视为价值为零，不将服务完成率解释为所有动物的保护比例。原题指出的犀牛偷猎问题继续作为定性挑战证据；其冲突记录保留备查，专项量化不再是本轮必要修改。这里仅调整修改计划，正式论文和计算结果尚未改变。

先落实不用等新数据的修改：清理文字与版式、统一输入范围和指标解释、修改二阶段目标、把已有紧张资源与网格敏感性结果写清。任何算法修改都重新求解，不能用本轮可行性结论代替求解结果。

随后利用已有六类动物数据补充物种权重和检查效率情景，检验“物种相对权重改变后部署是否变化”和“技术等效假设改变后地面任务是否回来”。现有资料可以检验假设的影响，不能认证哪组参数是真实最优。黑犀牛加入情景保留为可选扩展，不作为本轮完成条件。

黄石迁移可以利用已取得资料继续；奇特旺先处理边界口径和完整虎数据。两项未闭合时，保留条件性试验的范围，暂不写成当地实际人员建议。
