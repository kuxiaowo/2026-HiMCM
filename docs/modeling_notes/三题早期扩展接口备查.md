## 1. 索引与接口

`i`为17个父级空间区，`j`为区内评价目标，`k`为威胁，`b`为驻点，`t`为月份内班次，`r`为人员技能组。区内评价点用于道路/技术覆盖，不能把父区中心视作全区，也不改变原动物统计单元。

| 层 | 输入 | 输出 |
|---|---|---|
| 数据处理 | 数量、法规分类、生态、路网、火、降雨及质量标记 | 价值、暴露、时间矩阵、缺失状态 |
| 第一题 | 价值、暴露、重点对象 | 需求`D_ikt`、保护指标及目标 |
| 第二题 | 第一题接口、人数/设备上限、驻点与班次 | 人时`x`、机时`h`、响应/人员安排及分数 |
| 第三题 | 第一题目标、技术与制度条件、第二题初始方案 | 最小可行编制、轮班和逐期保障情况 |

## 2. 需求和保护指标

定义`D_ikt=θ_k V_ik H_ikt`。同一比较情景内固定价值、需求和归一化尺度。偷猎暴露为道路进入便利度，火暴露为历史过火代理加明确的年景情景修正；都不声称真实事件概率。

设同区同威胁的目标需求权重`ω_ijkt=D_jkt/D_ikt`合计为1，且`D_ikt=Σ_j D_jkt`。权重需同时反映区内对象分布与暴露，可随月份/班次改变；未知分布采用明确的均匀/热点/重点对象情景，不称实测分布。目标点服务为`g_jkt=d_jkt r_jkt`，先逐点结合发现和响应，再求`g_ikt=Σ_j ω_ijkt g_jkt`。若先用区域需求再分摊，必须说明分摊为需求权重，不能只按面积忽略区内暴露差异。

全园分数及未满足需求：

\[
P_t=100\frac{\sum_{i,k}D_{ikt}g_{ikt}}{\sum_{i,k}D_{ikt}},\qquad
L_t=\sum_{i,k}D_{ikt}(1-g_{ikt}).
\]

这是模型内服务评分。需求为零时不适用，关键需求未知时不输出完整全园分数。重点对象另设底线，盐沼/水源生态监测可设独立服务要求，不能仅靠六类动物份额代表所有生态功能。

第一问仅确定考虑因素、数据量化与保护成效判据。具体分数阈值、响应期限、监测频次和资源作用留给后续模型确定；此前80分、重点0.90、到场30/60 min等均为未验证的规划示例，备查见[指标与验证技术笔记](modeling_notes/protection_metrics_and_validation.md)，不作为第一问结论。资料完整且所有底线/辅助要求通过才判定达标；代码`evaluate_protection_standard`拒绝以不完整范围认证全园保护。

## 3. 资源作用与可行性

发现能力基准采用`d=v_jkt min(1,Σ a_jbkt x_bikt + Σ c_jbkt h_bikt + s_jkt)`，`v_jkt`为固定情景下的核查/有效观测质量因子，缺少额外校准时可取明确基准1并测试折减。系数吸收有效投入强度、可达作业范围与统一效能假设；`s`只给适用的信息服务，火卫星不赋偷猎发现能力。`x`包含出行占用但贡献按有效巡查；`h`含往返但贡献按现场有效飞行。系数需有来源或假设范围；任务价值只影响需求，不再重复增加发现能力。

第一版及时响应`r_jkt`取0/1：有合格队伍在该班次值守，并可在选定期限内到达该目标，则具备该响应能力。路网时间、道路外时间和核查/调度用同一截止口径。若采用起事至到达的总期限，还需扣除明确的发现等待情景；不能把观测后发布延迟当全部发现等待。

固定驻点、响应队开关和可达矩阵决定点级覆盖。重叠覆盖取并集；多个目标共享值守队依赖稀疏事件假设，并发情景另检查。对0/1的`r`，乘积`g=d r`可精确线性化：`0≤g≤d`、`g≤r`、`g≥d+r−1`。

发现的饱和函数在固定质量因子`v`下可用`d≤v`、`d≤v×投入贡献`表达上限；最大化正需求服务时可取到饱和值。零服务收益或仅求人数时这些上限不强制`d`恰等于真实饱和值，因此求解后仍按实际投入重算评分。连续非二元响应评分的乘积不能只用一般McCormick包络就声称精确解，应改用离散化并检查误差或单独求解非线性模型。

人员预算：巡查/核查占用＋响应值守＋无人机配套＋卫星信息处理≤当班可用人时。响应预留工时计在驻点一次；多个区域不能重复算作多支队伍。设备机时、航程与班次上限同时满足，技能与同时岗位单列。

## 4. 第二题的方向

给定可用保护人数与技术上限，最大化需求加权的保护服务，或等价最小化未满足需求；重点对象底线属于约束。单期固定需求时两者等价；跨期若最大化各班次平均分则需分别除以每期总需求，不与最小化未满足总需求混用。多期目标可按期长加权，但必须同时报告最弱班次。

选MILP实施，固定响应安排后可先求连续线性规划作演示。基准为同预算均匀部署/需求比例部署；现有真实部署只有取得数据才能作现状基准。

## 5. 第三题的方向

以`min Σ_r N_r`为目标，允许地面人时、机时和响应安排在同样技术条件下重配置，要求每个关键`t`的`P_t≥η`和重点对象服务达标。第二题配置是可行初始方案，不是固定不可更改的输入。

轮班模板`ℓ`满足工作上限和休息，人数`n_rℓ`为整数，当班供给为`Σ_ℓ a_ℓt n_rℓ`。岗位工时与并发需求不能超过供给，`Σ_ℓ n_rℓ≤N_r`；跨技能共用人员需要共享容量约束。各月份重排同一编制，总人数不能按月相加。

先报保护岗位编制及同时在岗，再根据已知非保护岗位或明确比例换算部门总人数。休息、休假、维护、备用等损失只扣一次。工时除单人工作量仅给下界；最低人数需要优化及排班可行性支持。
