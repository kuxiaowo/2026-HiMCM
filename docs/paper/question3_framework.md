# 3 季节需求下的保护服务评估与人员需求模型

## 3.1 服务目标与基本设置

### 3.1.1 第二题接口与基准服务目标

第三题分别回答固定人数能维持多少服务、保持所选服务需要多少人。复用第二题的17区、599检查单元、权重 \(w_j\)、需求 \(C_j\)、作业成本 \(a_j,b_j,\gamma_j\)、响应可达性 \(r_j\) 和区域底线，不重复推导分区及赋权。

保持全年同一基准目标：

\[
P_t=100\sum_jw_js_{jt},\qquad \eta=P_2^*\approx57.26.
\]

说明目标取自第二题已实现的最优服务，评分口径不随月份变化。

### 3.1.2 月度口径与资源参数

以12个标准30天月为规划期，有效工时固定 \(q=120\) 小时/人月；参考保护岗位 \(N_0=295\times0.2=59\)，对应7080人时/月。沿用共享响应 \(H_0=2880\) 人时、无人机上限 \(U=240\) 机时，允许逐月重新配置。参数表区分继承输入和新增服务假设。

## 3.2 季节服务工作量

### 3.2.1 季节窗口与月份划分

依据[研究的旱湿季分类](https://datadryad.org/dataset/doi:10.5061/dryad.4qrfj6qm3)和[官方火管理策略](https://www.meft.gov.na/files/downloads/66c_Fire%20Management_Strategy%20Final%20Version.pdf)，将月份归为四组：

|时期|水点规则|额外火险检查|
|---|---|---|
|1—4月、12月|湿季|常规|
|5—7月|旱季|早期加密|
|8—10月|旱季|重点加密|
|11月|湿季|重点加密|

先交代时间依据，再明确具体增加频次为规划假设。11月虽采用湿季水点规则，火管理加密仍持续。

### 3.2.2 额外火险检查需求

令 \(A_j^F=\rho_i^F A_j\) 为单元可燃生境面积，\(\rho_i^F\) 为区域同口径可燃比例；参考面积 \(A_{\mathrm{ref}}=100\ \mathrm{km}^2\)。中档额外频次 \(k_t\) 为常规0、5—7月2、8—11月4点次/参考面积月，得到

\[
D_{jt}^{\mathrm{all}}=k_t\frac{A_j^F}{A_{\mathrm{ref}}},\qquad
D_{jt}=r_jD_{jt}^{\mathrm{all}}.
\]

新增任务是独立火险筛查，沿用原检查成本；原检查不重复计入新增量。优化要求完成可响应部分 \(D_{jt}\)，不可响应需求另行记录。

### 3.2.3 人工水点运维人时

采用[原研究](https://koedoe.co.za/index.php/koedoe/article/view/1329/1890)中的17处历史BH钻井样本，地面完成抽水系统巡检、清理和小修。每处从六候选驻点择最短完整往返时间 \(T_\ell^{\mathrm{rt}}\)，两人同行，每次准备 \(1/12\) 小时：

\[
W_t=\sum_{\ell\in\mathcal L}f_t\,2
\left(T_\ell^{\mathrm{rt}}+\tau_t+\frac1{12}\right).
\]

中档湿季、旱季分别2、4次/月，现场 \(\tau_t=0.5\) 小时；异常干旱运维压力为8次/月、1小时。频次由目标间隔换算，路线时间由路网计算；无人机不能替代这项地面工作。由合计往返42.87565小时，得到湿季211.17、旱季422.34、压力下980.68人时/月。

## 3.3 月度服务评估与人时优化

### 3.3.1 决策变量与共同约束

\(x_{jt},h_{jt},s_{jt}\) 分别为基准监测地面人时、机时和完成率；\(y_{jt},v_{jt}\) 为额外火险人时、机时，合记为 \(\mathbf z_t\)。令 \(\mathcal J_R\) 为可响应集合，\(\mathcal J_U\subseteq\mathcal J_R\) 为无人机适用集合。

对 \(j\in\mathcal J_U\)，分别满足基准和新增任务容量：

\[
C_js_{jt}\le\frac{x_{jt}}{a_j}+\frac{h_{jt}}{b_j},\qquad
D_{jt}\le\frac{y_{jt}}{a_j}+\frac{v_{jt}}{b_j}.
\]

仅地面单元删除机时服务项；不可响应单元监测投入为0。保留非负工时、\(0\le s_{jt}\le r_j\)、共享机时和原区域底线：

\[
\sum_{j\in\mathcal J_U}(h_{jt}+v_{jt})\le U,\qquad
\sum_{j\in\mathcal J_i}\mu_js_{jt}
\ge\beta\sum_{j\in\mathcal J_i}\mu_jr_j,\quad\beta=0.15.
\]

总人时为

\[
H_t(\mathbf z_t)=H_0+W_t+
\sum_{j\in\mathcal J_R}(x_{jt}+y_{jt})+
\sum_{j\in\mathcal J_U}\gamma_j(h_{jt}+v_{jt}).
\]

共享响应只计一次，所有任务共用人员和机队。将以上容量、适用性、机时及底线约束记为共同可行集合 \(\mathcal F_t\)。

### 3.3.2 固定人数的服务水平评估

给定59个保护岗位，逐月最大化同一基准服务分：

\[
P_t^*(N_0)=
\max_{\substack{\mathbf z_t\in\mathcal F_t\\H_t(\mathbf z_t)\le qN_0}}
100\sum_jw_js_{jt}.
\]

报告月度服务及目标缺口 \(\Delta P_t=\max\{0,\eta-P_t^*(N_0)\}\)，回答同一人数面对季节任务变化时能维持多少服务。

### 3.3.3 固定目标的最小人时模型

保持目标 \(\eta\)，移除7080人时上限，反求最少总人时：

\[
H_t^*(\eta)=
\min_{\substack{\mathbf z_t\in\mathcal F_t\\100\sum_jw_js_{jt}\ge\eta}}
H_t(\mathbf z_t).
\]

服务向量允许重新选择，不锁定第二题某个代表解。\(H_0,W_t\) 虽为单月常数，仍完整进入人员需求；固定资源与固定目标两类模型使用相同服务约束。

## 3.4 求解与人员需求换算

### 3.4.1 月度求解与基本核验

按“读取第二题输入 → 生成 \(D_{jt},W_t\) → 构造共同约束 → 分别求两类LP → 汇总结果”执行，采用HiGHS。检查服务容量、必要任务、区域底线、人时与机时；无解时记录原因。

正文仅简报核验通过。极小权重处理、Q2成本复现及逐项校核放[计算记录](../第三题模型实算.md)和[独立核验附件](../../output/question3/q3_independent_verification.json)，不再单列数值处理、同时人员数等三级小节。

### 3.4.2 月度人数与全年固定配置

每人有效工时固定120小时，人数按最小人时向上取整，全年固定人数取最紧张月份：

\[
N_t^{\mathrm{plan}}=\left\lceil\frac{H_t^*(\eta)}{120}\right\rceil,\qquad
N_{\mathrm{year}}^{\mathrm{plan}}=\max_tN_t^{\mathrm{plan}}.
\]

说明各月人数不相加，年均人时不能替代逐月达标；追加岗位相对参考59人计算。

## 3.5 结果与人员配置解释

### 3.5.1 固定59人的月度服务

中档季节方案全年保持57.26分。新增工作消耗预算余量，但峰值6831.83仍低于7080人时，因此需求上升没有造成服务分下降。用月度工作量与评分曲线解释这一结果。

### 3.5.2 季节人时与全年人数

|时期|人时/月|规划人数|
|---|---:|---:|
|1—4月、12月|5497.28|46|
|5—7月|6270.14|53|
|8—10月|6831.83|57|
|11月|6620.66|56|

峰值构成为

\[
2880+2406.11+1123.38+422.34=6831.83,\qquad
N_{\mathrm{year}}^{\mathrm{plan}}=\lceil6831.83/120\rceil=57.
\]

四项依次为响应、基准监测、额外火险和水点运维。解释11月火管理仍加密，所以需56人而非回到常规46人。

### 3.5.3 异常干旱下的追加人员

只提高旱季水点访问频次与现场耗时，其余条件保持。峰值需求7390.17人时，对应62人；固定59人时，8—10月服务降至54.97分。相对参考配置追加3人，相对中档57人方案增加5人，结论注明比较基准。
