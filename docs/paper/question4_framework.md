# 4 敏感性与情景分析

## 4.1 资源敏感性分析

### 4.1.1 人员减少对保护服务的影响

保持其他条件不变，减少人员预算，计算服务分和区域缺口，寻找不能维持基准目标的资源阈值。单人有效工时固定120小时，响应预留不同比削减。用一张曲线说明何时仍可维持服务、何时出现不足。

### 4.1.2 无人机减少与人力替代

减少可用机时，观察地面检查、无人机配套人工和服务分的变化；必要时反求维持同一目标所需人员。即使分数不变，也要说明是否增加人工消耗。

## 4.2 关键参数敏感性分析

### 4.2.1 通行与作业条件的影响

以道路速度和作业耗时为主要参数，重算响应范围与单位成本，判断限制来自地理可达性还是资源不足。技术替代条件只选有依据的代表情景，不逐项扩展所有设备参数。

### 4.2.2 季节服务要求的影响

改变额外火险检查频次、水点访问频次及现场耗时，比较固定人员下的服务和固定目标下的人员需求。先区分单因素影响，再引用已有低、中、高档组合；水点清单工作量、赋权和格网对照作为补充或附件。

## 4.3 情景分析与策略调整

### 4.3.1 巡护时间安排的比较

保持月度资源和任务总量，比较分散与集中安排，检查分时工作容量及水点最长访问间隔。说明月总工时足够是否仍存在时间缺口，不建立复杂轮班模型。

### 4.3.2 联合压力下的部署调整

选少量“人员减少＋无人机减少”“旱季任务增加＋设备不足”组合，比较保留原空间规则与允许重新配置的结果。原规则不满足预算或底线时报告不可行；最后归纳主要瓶颈和调整建议。
