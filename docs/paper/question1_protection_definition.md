# 第一问：考虑因素、数据量化与保护成效

## 1. 主要挑战及优先级

| 暂定管理优先级 | 挑战 | 判断依据 |
|---|---|---|
| 1 | 偷猎与非法进入 | 原题明确指出持续犀牛偷猎压力；重点物种的非法损失具有不可替代性，可通过巡护和执法干预 |
| 2 | 有害野火与生境破坏 | 原题指出野火影响大范围公园，可同时威胁动物、植物及生境；计划烧除与有害火需区分 |
| 3 | 降水不足与气候压力 | 长期降水异常影响生态条件；仅有降水不能确定实际供水状况，暂不建立具体水源模型 |

上述顺序依据威胁证据、潜在损失、影响范围和可干预程度暂定。缺少同口径事件与损失数据，不能认定这是实测风险高低排序；区域、季节及已发生事件可改变顺序。人兽冲突、疾病等保留为待补事项，不因缺数据判为低风险。

## 2. 考虑因素及量化处理

按现有17区组织数据：15个动物调查统计区、主盐沼与其他调查外区域。动物、生态、道路资料分别来自2015、2021、2026年，作为规划基线。

| 因素 | 数据处理与量化 | 模型含义 |
|---|---|---|
| 面积与分区 | 统一坐标，修复重叠与缺口；动物密度用原调查面积，空间作业用几何面积 | 评价范围与单位面积投入的基础 |
| 动物数量与保护类别 | 按物种、调查区关联数量；先求同物种区域份额，再按保护类别加权 | 动物区域保护责任 \(V_i^A\) |
| 植被与重要生境 | 地类面积除以有效分类面积得到比例；草/灌/林面积份额作为可燃生境责任，重要植物地点另记 | 生境结构及火侧对象责任 \(V_i^F\) |
| 道路与进入条件 | 最短进入时间转为 \(E=\exp(-T^E/\tau_E)\)；保护驻点到目标的通行时间另算 | 人为进入便利度及响应可达性，非偷猎概率 |
| 历史过火 | QA筛选后逐年对晚旱季过火范围去重；过火面积/有效可燃面积，再取多年平均 | 火暴露 \(F_i\)，非起火概率或有害损失 |
| 降雨 | GPCC格网按区域相交面积加权；以1971—2020年完整雨季拟合SPI-6，并取\(\delta=\operatorname{clip}(-SPI/2,0,1)\) | 独立降水不足背景，不推算水点状态、火险概率或自动增加人员；距平仅辅助解释 |

动物责任和生境责任分别量化：

\[
V_i^A=\frac{\sum_s w_s(n_{is}/N_s)}{\sum_s w_s},\quad
N_s=\sum_{i\in I_S}n_{is};\qquad
V_i^F=\frac{A_i^F}{\sum_i A_i^F}.
\]

其中 \(n_{is}\) 为区域数量，\(I_S\) 为调查范围，\(A_i^F\) 为可燃生境面积。第二题采用可猎/保护/特别保护三类别AHP判断权重0.1634/0.2970/0.5396，CR=0.0079，数值为团队判断而非法定规定。此前1/2/3历史基线保留作对照，不冒充当前AHP结果；数量和密度不重复加权。黑犀牛冲突数量暂不入主表，但保留重点保护地位。调查外或缺测值保持未知；盐沼燃料基准为零不代表生态价值为零。已完成1971—2024年648个月的17区降水序列及49个完整基准雨季SPI，具体水源数据和专门水源工时不再纳入。

## 3. 保护是否有效的评价

“受到保护”指：重点对象能够按规定服务标准被巡查与监测，异常能够核查，合格队伍能够及时响应，并保持必要生态监测。具体服务频次与到场条件由第二题明确；完成代表点检查不等于整区连续覆盖。

对同一目标、威胁和时段，用有效巡查/监测覆盖与核查记录量化 \(d\in[0,1]\)；响应能力 \(r\) 基础版取“合格队伍可在所选期限内到场”为1，否则为0。服务分数为 \(g=dr\)，先在目标点计算，再按需求汇总；投入如何转为能力在后续模型中确定。

\[
D_{ikt}=\theta_k V_i^kH_{ikt},\qquad
P_t=100\frac{\sum_{i,k}D_{ikt}g_{ikt}}{\sum_{i,k}D_{ikt}},\qquad
L_t=\sum_{i,k}D_{ikt}(1-g_{ikt}).
\]

\(D\) 是相对保护需求，\(H\) 是对应威胁暴露，\(\theta\) 是管理权重；\(P\) 是保护服务评分，\(L\) 是未满足需求。分项分别归一化后用固定管理权重汇总，以免物种份额与火面积量纲主导分数。反偷猎侧以 \(E\) 为暴露代理；多年\(F\)尚缺，第二题暂用可燃生境等暴露情景，不把2022年9月单月样例当多年风险。降雨单列气候背景，不直接改变主资源模型；已知对象评分不能代替缺失的重点物种/生境评价。

| 评价层次 | 判据 |
|---|---|
| 模型内能力 | 同一需求条件下，\(P\)提高、\(L\)降低，且重点对象最低服务及必要生态监测要求达标；具体阈值在资源模型中确定 |
| 实际动物保护 | 非法动物损失率及重点种群状态，用可比调查与事件记录检验；检出事件增加不自动表示保护变差 |
| 实际生境保护 | 有害非计划火对重要生境的影响及关键生态状态；不能把全部过火面积都当作保护失败 |

评分衡量保护能力，实际成效需另用生态和事件数据验证，并控制监测努力、季节及环境差异。关键数据未知时不出具完整评分；全园平均分不能替代重点对象底线。
