# 论文方法：空间分区与数据匹配

日期：2026-10-05。状态：第一版空间分区、动物表关联、几何QA和最终17区生态提取均已执行，以下方法与结果对应本轮保存成果；资源配置、实际火暴露指标和效能校准尚未完成。文中“精度”与“覆盖”只表示相应检查范围，不将拓扑合格称为官方边界认证。

## 1. 分区原则与选择依据

研究将埃托沙国家公园划为资源配置的空间评价单元。空间单元应同时支持动物价值统计和道路、土地覆盖、水源、过火资料的叠置。公开可得的2015年旱季航空调查提供15个数量统计单元，因此第一版优先与该调查尺度保持一致，减少将数量无依据拆到新生态小区的误差。不同生态类型不要求各自构成独立区域，而是在每个评价单元内保留面积结构，支持不同威胁和栖息地的计算。

这里的调查单元是分层抽样统计单位，不应称作现行管理区或天然生态边界。调查中`ENP3`、`ENP4`、`ENP10`合并为`ENP3410`，使用同一数量键；合并估计不能拆为三个独立实测数量。如果GIS几何包含多个子面，子面共享同一统计键，以避免重复计入动物。

调查总范围18,551.14 km²排除主盐沼，而研究对象仍是整个公园。因此主盐沼必须独立保留；所有无法匹配调查范围的其余部分也需显式保留为补充区或残差区。该类区域的未调查动物值为未知，不赋零；可根据鸟类、植物和重点栖息地的另外资料补充价值。

最终采用17个父级建模单元，即15个调查统计单元、主盐沼近似单元`PAN_MAIN`和其他调查外残余`UNSURVEYED_OTHER`。它们不必各自连续；17单元共有191个几何部件，ENP3410含3个实质部件，残余单元含172个部件，包含细小边界残余。部件仅用于空间定位，不能重复关联父区数量或当作独立实测调查区。

## 2. 原始资料与坐标处理

公园边界采用项目现有OpenStreetMap边界（关系2982497，纳米比亚2026-10-03快照），来源文件和下载校验保存于`data/roads/`。分区坐标取得自IUCN非洲象数据库2015调查提交722的公开地图接口，该地图提供15个统计单元，`ENP3410`由3个部件组成。坐标来源和归一化结果保存于`data/regions/raw/source_audit/`。用Kilian（2015）《Aerial Survey of Etosha National Park》第5页图1核对分区位置，第6页表1核对统计面积，物种数量采用第7—12页对应分区表。

公开坐标属于概化/量化的网页地图资料，不视为调查原始GIS；公园地图边界也不称法定界线。接口未显式声明CRS，按经纬度量级推断WGS84/EPSG:4326，保存为数据假设。

源空间文件保留WGS84地理坐标，分区叠置、面积加总和拓扑QA采用局部Lambert方位等面积投影（LAEA），投影中心为19°S、15.75°E，参数`+proj=laea +lat_0=-19 +lon_0=15.75 +datum=WGS84 +units=m +no_defs`。投影前在EPSG:4326中将所有源线段加密至不超过0.001°，保持GeoJSON与Rasterio使用的经纬度直线含义，避免长边仅投影端点导致逆投影轮廓不一致。

最终公园边界LAEA面积为22,906.862606 km²，椭球面积22,906.862607 km²。未加密稀疏节点Geod面积22,904.736846 km²只作参照：后者将长线段解释为节点间的大地线，与前者的地理坐标直线含义不同；面积差不表示人工扩大边界。旧道路UTM面积22,897.100933 km²只属旧版本诊断，不用作本轮分区覆盖分母；道路长度和路由仍采用其既定UTM33S/EPSG:32733。

每区同时保存`area_laea_km2`（拓扑和可加面积）、`area_km2`（WGS84椭球面积）与`survey_area_report_km2`（2015调查表面积）。物种历史密度按原报告对应面积重算；空间覆盖统计使用实际几何或栅格分配面积。重建几何差异不自动导致原数量缩放。

实际处理流程如下：

1. 将AED接口中的几何项补为标准GeoJSON Feature，保留原坐标和属性，统一统计区编号。
2. 在EPSG:4326中加密源分区与园界至最大0.001°线段，再投影到LAEA。
3. 将小于0.1 km²的源孤立部件转入调查外残余，不从公园范围删除。涉及ENP11约0.001293 km²和ENP13约0.044008 km²。
4. 裁切到所选OSM园界。依据报告图1先从ENP11扣除ENP9；剩余重叠按表1面积小区优先分配。后者是拓扑修复假设，并非官方界线事实，逐区修改面积完整保留。
5. 将未归属范围保留为调查外残余。以500 m负buffer提取其内核，保留最大部件，正buffer恢复后与原残余取交，得到主盐沼近似单元；其余保留为其他残余。
6. 保存父区、几何部件和原始/修复图层，核查有效性、覆盖、重叠、数据键及输出回读，并直接在原EPSG:4326中检验与原园界的一致性。

报告图1 JPEG用于结构目视对照，本轮未对其地理配准，因此没有控制点或配准残差。原图西南无编号条纹块缺明确图例，保留在调查外残余，不强行并入ENP1。修复后ENP11为1主体，不能由原图两个编号推成两个独立区。成果称“基于AED公开地图坐标，并参照2015调查图修复的近似统计分区”。主盐沼的形态法范围不等于独立观测的土地覆盖多边形。

源核查显示原15单元虽然各自几何有效，但未经加密的椭球面积和19,094.710545 km²与并集18,464.479879 km²之差约630.230667 km²；ENP9与ENP11重叠约580.497945 km²。约94.106300 km²原分区落在所选OSM边界外。以上为早期来源诊断，说明不能将公开坐标未经检查直接作为互斥分区。最终修复规则以报告图为依据并记录明确优先序，不以面积拟合替代位置核查。

最终源线段加密后的LAEA流程修复前超额重叠为630.395016 km²。来源诊断与最终流程在几何解释、面积算法上有差异，最终覆盖与重叠统一采用LAEA并辅以原EPSG:4326回读检验，不混合加总不同口径来判定缝隙。

## 3. 生态类型如何参与统计

土地覆盖采用ESA WorldCover 2021 v200（产品2.0.0）的分类资料。本轮已下载S21E012、S21E015两瓦片，保留原生EPSG:4326网格拼接裁切，不对分类值插值。统计通过像元中心分配到区域，按纬度行计算各像元四边形WGS84椭球面积；不是已完成像元与边界的面积分数相交。类别k的区内面积为分配像元中该类像元面积之和，比例为：

`g_i,k = assigned_valid_area_i,k / assigned_valid_area_i`。

有效覆盖率另按有效分类面积除以所有分配像元面积计算，并记录矢量面积与像元覆盖面积差异。实际原生像元面积约80.7034—81.1719 m²，不统一设为100 m²。矢量面积按地理坐标直线加密至0.001°后积分，口径与分区相同；全园中心分配像元面积22,906.914054 km²，比矢量椭球面积高0.0002246%，有效覆盖率100%。最终17区有效像元面积合计与全园之差约5.09×10⁻¹¹ km²，各区最大绝对矢量—像元相对差异约0.01912%（ENP7）；固定400个原生像元抽样比对无差异。有效覆盖100%不表示分类准确率100%。类型编码只作为类别，不能以数字大小作连续归一化，也不设置全园统一的“林地价值高于草地”排序。

草地、灌丛及林地（代码30/20/10）作为基准潜在可燃生境，独立主盐沼单元显式排除，其他裸地不自动等于盐沼；农田和草本湿地未纳入基准，可另作掩膜情景。后续在目标火季内，可靠观测过火面积与同一可靠可燃范围面积构成年度比例，再取多年平均；生态类别不证明火强度或实际有害性。

全园原始林/灌/草代理为17,763.377438 km²；主盐沼内仍有150.076423 km²、占3.60224%的原始代理，因此掩膜后各区基准合计为17,613.301015 km²。主盐沼类别中裸地/稀疏植被约95.74174%。基准中将盐沼燃料代理设0是掩膜假设，不能称其绝无可燃植被；原始面积字段保留用于敏感性。该0亦不同于调查外动物数量的null。

植物保护分项使用已确认出现位置，或有独立依据的重要群落/栖息地范围。WorldCover林地面积不能直接解释为珍稀植物面积。只有全园动物数量而缺分区数量时，适宜生境可用于明确标记的空间分摊；已有分区数量的物种不因生境面积多再重复加价值。

## 4. 动物数量表的关联与质量保留

数量表通过原始统计单元编号关联区域，至少保存估计数量、调查面积、95%区间、来源页、年份、季节和质量状态。数量和密度用于解释同一动物分布，不能同时作为独立价值项重复加权。

候选主方案采用大象、长颈鹿、平原斑马、南非剑羚、蓝角马和鸵鸟六类历史估计；法定保护类别形成共享建模权重。为避免自然数量特别多的物种主导评分，可先计算该区数量占该物种同一调查范围总量的份额，再作类别加权；这种分数表示选定物种的区域保护责任，不能称全园完整生物多样性。

本轮保留原165条区域—物种记录，补充两个调查外单元的22条未知记录，共187条；无重复关联键和未关联原行。六类候选表含102条记录，其中调查外12条为null。该处理只完成空间关联，没有改写原数量，也未把历史值转换成2026现状。

源表空白、调查未检出、调查范围外未知分开编码。数量空白而密度明确为0的已调查行，如基准情景采用0，须保留“基准未检出假设”，不当作确定不存在。黑犀牛存在正文与表格矛盾以及分区合计1,107、汇总1,280的冲突，在核验前不进入主数量矩阵；重要物种仍通过有依据的生境补充或单列情景保留作用。Eland、跳羚等其他疑点亦保留原值和质量标记，不自行补字或用归一化掩盖。

若未来改用新的生态分区，应先构建调查单元与新分区交叉表，再通过明确的面积或适宜生境权重分摊。须保证每一来源单元的份额总和为1并检查物种总量守恒；所得数值为估计分布，不是新分区实测数量。原调查外区域不能通过该过程自动获得伪观测值。

## 5. 降水尺度与缺失方案

空间分区不以分区雨量站齐全为前提。用户最新确认有50年逐月记录，但实际文件、来源和空间范围尚未收到。只有全园雨量时各区共用气候指标，多区资料核验后才生成分区异常。最新设计采用完整雨季SPI-6派生一个不足指数，距平仅解释，详见[降水指标设计](../降水指标设计.md)。

取得逐月格网后，对每个区域按像元与区界相交面积求平均降水深度，再累计前一完整雨季。初设雨季为11月至次年4月，需由实际季节曲线确认。雨季距平率定义为同一来源、固定基准期下的雨季累计量与均值之差除以均值；完整历史记录可支持SPI-6替代，但二者不同时独立计分。降水作为水源压力和后续燃料的背景修正，不能假定少雨必然增加火风险。

## 6. 质检与复现报告

以下结果已保存于`output/regions/partition_quality_report.json`，几何QA使用1 m²数值容差；容差不是来源边界的位置精度：

| 检查 | 计算或规则 | 结果状态 |
|---|---|---|
| 几何有效性 | 源15单元及最终17单元有效；空/重复区号 | 均通过，空/重复为0 |
| 全园覆盖 | `area(park − union(regions))` | 0 m²；覆盖100% |
| 园外部分 | `area(union(regions) − park)` | 0 m² |
| 重叠 | 分区面积和减并集面积，并检查两区正面积交叉 | 超额面积0；最大交叉约4.29×10⁻⁷ m² |
| 输出回读LAEA | 保存GeoJSON并集与园界对称差 | 约0.0000869 m² |
| 对原地理坐标园界核验 | 回读分区与原EPSG:4326园界的缺口/外溢 | 约0.00640/0.00186 m² |
| 源表面积对照 | 逐区原/修复面积与报告面积、裁界/去重变化 | ENP8/ENP9差异超过5%，已标记 |
| 统计键完整性 | 15来源单元各关联一次；ENP3410不拆计 | 通过 |
| 数量表关联 | 165源行保留，调查外未知单列 | 187行，重复/未关联原行0 |
| 图形核查 | 报告分区结构、编号、主盐沼与西南残余 | 已作结构对照，无地理配准声明 |

LAEA下15调查单元合计18,371.938512 km²，主盐沼近似单元4,166.148350 km²，其他残余368.775744 km²，三项合计22,906.862606 km²。ENP8和ENP9几何面积比报告分别低12.84839%与13.98582%，保留质量标记；5%是提示进一步核查的筛选阈值，不是普遍精度标准。不能按几何差缩放原动物数量或以报告面积强行扩张区界。

主盐沼的250/500/1000 m开运算情景面积分别为4,173.227159/4,166.148350/4,163.301687 km²。将其他重叠的优先序反向，同时保持ENP9从ENP11扣除，最大单区面积变化22.885561 km²，最大相对变化1.23489%。这是几何面积敏感性，尚不能说明空间因子排序与资源分配结果稳定。

空间输出应保存区域编号、名称、调查键、区域角色（调查匹配/主盐沼/补充或残差）、源面积、几何面积、来源、重建方式和不确定性标记。额外数据缺失和数值误差阈值分别记录，不能以“填补缺口成功”宣称边界准确。

`region_neighbors.csv`的45条500 m以内邻接仅作地理描述，禁止将多部件父区或残余整体当成路由节点。通行时间应继续在道路图上计算，并连接到部件内目标位置。

重建脚本`scripts/regions/build_model_regions.py`、`environment-regions.yml`、输入校验、参数和软件版本记录于`partition_build_manifest.json`。本轮实际使用conda `himcn-roads`，Python 3.12.15、GeoPandas 1.2.0、Shapely 2.1.2、pyproj 3.8.0；环境配方名为`himcn-regions`。分区与软件版本可复现，来源地图的位置误差仍需另行解释。

## 7. 可用于论文的限制说明

本研究分区以公开历史调查尺度为基础，并以公开地图和遥感产品开展叠置。公开调查地图坐标为概化资料，原图核对与拓扑修复仍包含位置和边界不确定性，调查面积对照仅提供一致性检查，不能将无重叠全覆盖解释为官方精度认证。2015动物、2021土地覆盖、2016—2025过火与2026道路年份不同，结果解释为统一假设下的静态规划示范。动物数量、植物记录和调查外生境的缺失不等于生态价值为零；仅选定六类大型动物不能代表全部生物多样性。分区与火暴露的空间计算可验证数据处理链，但保护投入的真实效能仍需独立投入、事件和损失数据校准。
