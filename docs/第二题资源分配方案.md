# 第二题：已实施的资源配置模型

更新：2026-10-06。已完成数据处理、LP求解、资源/地理情景、独立预算核验和论文图表。本文是实施入口，详细公式与结果见[第二题正文](paper/question2_resource_allocation.md)，过程见[计算备查](modeling_notes/question2_calculation_notes.md)。水源与降雨均不纳入当前指标、工作量、情景及图表。

## 1. 数据和输入

17区作为报告单元，10km格网与各区相交的599个连通片作为地理检查单元。动物为2015六类历史数量、生态为2021WorldCover、道路为2026固定OSM快照，年限不同不称当前全园实测。AHP三保护类别权重0.1634/0.2970/0.5396，CR=0.0079，是法规类别支持的团队判断，不是法定数值或外部专家评分。

动物份额先在同物种调查范围归一化，结合进入时间指数形成反偷猎监测需求分项。可燃生境面积形成另一监测分项；单月火样例不当多年风险，主模型等暴露规划假设需以后校准。以15个共同有数据分区计算熵权，两分项分别归一化后按0.645551/0.354449组合，替代原手设比例；CRITIC作为方法敏感性，详见[赋权备查](modeling_notes/q2_objective_weights.md)。黑犀牛、植物、鸟类及调查外动物未知不填零，通用区域服务底线不能替代专项保护目标。


## 2. 标准和作业时间

每100km²每月8个合格检查点次，C_j=8A_j/100，避免格网变细凭空增加工作量。每片代表点用于规划路线，不证明全片连续覆盖。两种方式仅在同一合格筛查协议下替代；现场执法和消防不由影像替代。

六处营地/入口候选驻点均不称现有保护站；日间每点2人预留8小时×30日，H_0=2880人时。沿有向Dijkstra计算去返程，尊重单行和真实道路连接，另加道路外步行。默认管理车辆可通候选道路、30km/h，道路外4km/h；权限、地形障碍和门禁延误未实测。

单次地面人时a_j由往返/步行、准备、观测及两名队员计算。无人机道路附近移动部署，b_j是飞行往返与观察机时，o_j为两名人员的道路往返、准备、操作人时；配套系数γ_j=o_j/b_j因路线而异，不再用缺地理差异的固定γ。飞行速度40km/h、安全单次36分钟，观测10分钟、准备5分钟均为规划假设。

响应门槛r_j由最快驻点去程+道路外时间+10分钟调度是否≤2小时计算；配置排序按具备响应且往返最省时的候选驻点固定。无人机作业不证明现场能够到达。第一版稀疏事件假设，不分析详细并发排班。

## 3. LP及实施

变量x_j为地面监测人时，h_j为机时，s_j为服务完成率。最大化100Σw_j s_j，约束C_j s_j≤x_j/a_j+h_j/b_j、0≤s_j≤r_j、Σx_j+Σγ_jh_j+H_0≤H、Σh_j≤U。无人机不适用时h_j=0，每区保障可响应面积服务的15%最低要求。

现有人员参考295×假设60%可用于保护×每月120有效人时，H=21240；无人机30架×每日2机时×20日，U=1200。比例是月度资源可用量，不是同时在岗比例。两类资源比例由LP决定。HiGHS连续最优求解后保持最优总分，让全部服务比例重新选择并最小化人工消耗；不能称精确飞行排班或全园保护认证。

## 4. 实算结论

- 基准三种部署都达到57.26分地理上限；优化同分方案使用5286.11人时、144.34机时，地面响应及无人机配套人员仍不可缺。
- 人时减少40%至12744，优化、面积均衡、需求比例均为57.26分；同时停用无人机也达57.26分。资源仍较充足，不沿用旧预算的优势幅度。
- 三个新增道路节点前置响应候选中，面向ENP5的候选达到64.27分，额外480人时计入同一预算，不证明全园选址全局最优。
- 已完成20/40km/h路速、3小时期限、5/15km格网尺度及资源缩减/停用等情景，结果与限制见论文。

第三题用同一C、r、区域底线和机时限制，增加服务目标约束，最小化Σx+Σγ_jh+H_0后换算规划人数。第三题已同步177人/1200机时基线并重算，常规/干旱峰值57/62人，详细见[第三题精简方案](第三题精简方案.md)。
