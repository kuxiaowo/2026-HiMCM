# 50年逐月降水：精简指标设计

更新：2026-10-05。用户确认已有50年逐月降水，并提供GPCC V2025、0.25°的1971—1975年全球格网样例。本地已实际读取60个月并提取17区面积加权月序列，现已汇总1971—2024年648个月，提取17区并以1971—2020年49个完整跨年雨季计算SPI，最新已完成雨季为2024年。此前“只有12个月气候均值”的条件已被此次确认替代。样例记录见[检查说明](../output/rainfall/GPCC示例文件检查.md)。

## 1. 最终保留哪些指标

**资源模型只保留一个主降水指标：最近完整雨季的降水不足指数δ，它由雨季SPI-6转换得到。最新精简决定删除水源台账和专项检查，δ当前只作气候压力解释，不自动进入资源人时预算。**雨季累计雨量、历史均值、距平率和原SPI作为解释/质检字段，不各自独立加权。短期SPI-3仅作可选辅助，不新增主模型因子。

SPI度量相对于当地历史气候的降水异常，不是绝对湿润程度、动物死亡概率、水点断供率或火灾概率。拟合的是已有50年降水的统计分布，区别于没有数据支持的“资源投入—真实减损”拟合。

## 2. 原始数据检查

底表至少保存位置/区域、年份、月份、月累计降水、单位、来源及质量状态。

1. 确认是月累计深度mm；降水率、月平均日雨量等先按来源说明换算，不能直接相加。
2. 检查约600个连续月份是否齐全、重复、负填充值或异常值。真实0保留，缺失不补0。
3. 站点搬迁、观测制度/产品变化留质量记录；50年长度不自动代表资料同质。
4. 单站序列不称每区实测；一套全园序列只算一个共享指标。多站/格网资料按可信空间方法取得各区月平均降水深度，不能将像元mm直接相加。
5. 统计50年逐月气候均值并检查季节曲线，以确认雨季。所有方案比较使用同一固定基准，不能配置前后重新拟合基准制造改善。

基准期按实际完整记录确定。若评价历史时点，计算只使用该时点可得的基准资料；若用整个50年回顾分析，则明确为回顾性统计。另用最近30年基准复算作为趋势敏感性，不能混用两个尺度。

## 3. 主指标：完整雨季SPI-6

已核验11月至次年4月占各区1971—2020年基准年雨量约96%—97%，采用该完整雨季。跨园迁移时需重新核验当地季节窗口。

评价年y的雨季累计为：

\[
W_y=P_{y-1,11}+P_{y-1,12}+\sum_{m=1}^{4}P_{y,m}.
\]

将每年相同结束月份的累计值组成历史样本。例如4月结束的SPI-6，只和历年11月至4月的累计比较；不能把4月底与9月底累计混成一组。50个公历年不保证有50个完整跨年雨季：首个雨季可能缺上一年11—12月，必须剔除不完整窗口。

处理步骤：

1. 从完整共同基准雨季建立样本，记录有效年数和缺失年份。
2. 对正累计量拟合Gamma分布（形状、尺度由数据估计），真实零值按核验过的SPI实现处理零降水质量；检查拟合与经验分位是否一致。
3. 得到累计量在历史降水分布中的累计概率H(W)，转换为`SPI=Φ⁻¹(H(W))`。
4. 若数据全零、几乎常数、正样本不足或拟合明显不适用，则标记不适用/待检验，不强制生成SPI；可改用明确标为“经验分位指标”的非参数方案，不能冒称标准SPI。
5. 数值概率截断只防止无穷并保存标记，尾部估计不解释为可靠的极罕见事件概率。

这不是简单的`(雨量−均值)/标准差`，也不是只凭某年少雨比例推算SPI。SPI值取决于历史分布及波动。

保留原SPI的正负号：正值表示相对偏湿，负值表示相对偏干。为了表达0—1的降水不足压力，采用：

\[
\delta_y=\min\left(1,\max\left(0,-\frac{SPI_y^{wet6}}{2}\right)\right).
\]

| 雨季SPI | δ | 解释 |
|---:|---:|---|
| 0或更高 | 0 | 不因降水不足增加检查要求；湿年信息仍保留在原SPI |
| −0.5 | 0.25 | 较轻降水不足量 |
| −1 | 0.50 | 较明显不足量 |
| −1.5 | 0.75 | 更大不足量 |
| −2或更低 | 1 | 降水不足映射达到设定上限 |

**除以2及截断是团队的指数映射规则，不是水文定律或WMO规定的资源比例。**0—1统一尺度不赋予真实损失概率；可检查截断尺度1.5/2/2.5对资源建议的影响，不同时加入更多独立雨量因子。

## 4. 时间使用规则

- 完整雨季结束后，旱季部署采用最近已完成雨季的`SPI_y^wet6`及δ，表示此前雨季的背景。它不是每个旱季月的新SPI-6值，也不假定水量恒定。
- 雨季尚未结束时，不能使用尚未发生的月份凑全雨季。需要月度更新，可计算截至当月的滚动SPI-6，明确窗口并和历年同结束月份比较；与4月底雨季指标分开标记，不同时加权。
- 可选SPI-3用于识别短期异常，不作第一版资源权重。正常少雨季节的三个月通常也少雨，且短期恢复未必消除长期不足，因此不能只因3个月无雨就宣称异常干旱或仅因SPI-3正常就宣称恢复。
- 月资料支持月/季节尺度分析，不用于推断逐日雷雨、每日火险或事件调度。

## 5. 距平率作为解释字段

\[
R_y=(W_y-\bar W)/\bar W.
\]

例如雨季平均400 mm、某年280 mm，则R=−0.30，表示少30%。这两个数本身不能确定SPI，必须使用历史分布。均值为零时距平不适用。

R便于论文解释，SPI便于比较历史异常，δ便于统一表达降水不足压力。三者来自同一降水信息，不能当三个独立风险项加权。

## 6. 当前模型接口：删除水源工时，保留气候背景

见[第二题方案](第二题资源分配方案.md)和[第三题精简方案](第三题精简方案.md)。删除具体水源数据、H_water及H_water乘(1+λδ)规则，不再需要λ。

SPI和δ描述气候异常，不能直接推断断水、动物损失或新增巡查人时。当前保留为降水压力和时期解释，不自动改变物种价值、巡护频次、人员或火风险。若后续有可信的可干预工作量依据，再建立新接口。

不同区使用可信格网面积加权序列，但分区不提升原分辨率；全园共用因子统一乘所有权重再归一化会抵消。50年降水序列不代表50年保护部署历史。

## 7. 火灾分项如何处理

雨季降水可能影响后续燃料生成；极少雨又可能限制燃料。SPI不是实时火险。先将同年完整雨季SPI与随后晚旱季QA合格过火比例配对，检查关系方向和稳健性。若只有2016—2025火资料，每区仅约10个年配对；50年雨量不自动变为50年火—雨样本，多区共用雨量也不是彼此独立的气候样本。

关系弱或数据不足时，主模型继续使用历史火暴露，SPI仅用于年景解释和情景分析。不直接给火权重增加`降水不足δ`，不认为少雨必然火多。湿年原SPI与原雨量保留，避免仅用δ丢掉燃料背景。
