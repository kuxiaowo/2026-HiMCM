# 第三题：保护服务随时间变化与人力需求估算

> **第二题实施接口修订：**已求解599个检查单元并输出17区配置。以下概念式中的共享γ在实际计算替换为γ_j=o_j/b_j，纳入无人机移动部署的往返人时；服务门槛为0≤s_j≤r_j，基本响应H_0为共享驻点人时。更新分项熵权后，第二题基准地理上限57.26分，既有80分示例在相同驻点/响应条件下不可达；第三题不得直接沿用80作为可实现目标。时间分析和人数反求仍待实施。

## 1. 原题要求及与第二题的关系

原题第三项要求分析公园随时间受到多好保护，并估计维持所选保护水平所需人员。只给一个人数不足以完成第三题。

| 分工 | 给定什么 | 求什么 |
|---|---|---|
| 第二题 | 人时、设备、服务标准 | 最高需求加权服务完成分及资源配置 |
| 第三题：时间分析 | 同样人员与设备，分期服务需求 | 各期可达服务分、重点底线和缺口 |
| 第三题：人员需求 | 目标服务分、设备和标准 | 达到目标最省人时的配置，再换算规划人数 |

评分表达规划服务能力，不是实际生态保护成功率。基本响应条件及重点底线必须另检查。

## 2. 时间维度：先两个代表时期，再展开月份

建议先常规期与有依据的重点火管理期，必要时展开12个月。重点期月份需核对火资料和管理依据，不因缺少管理依据就断言火监测需求变化。

- 价值、路网、基准需求权重w_i第一版固定，不另建动物迁移和数量预测；统一权重便于跨期比较。
- 基准巡查频次不变；火管理观察确需增加时，只增加相关服务频次，并用一项全园共享管理规则，标明资料或假设。不同用途不能随意当同一种检查相加，必要时保留少量用途约束。
- 无季节日志时，单位作业时间和无人机可用机时固定；设备停用、道路封闭等变化放第四题情景。
- 单人有效保护工时按同一制度和评价期计算；基本响应人时按固定驻点及期长计算，共享驻点只计一次。

若需求、权重、设备和有效人时都不变，各期结果相同是合理结论，不能人为改参数制造变化。没有实际部署时序时，不能声称回测历史保护或人员变化。

## 3. 固定资源，先算各期保护服务

给定可参与保护人员N_0，该期预算H_t=N_0 q_t，其中q_t是单人该期有效保护工时；给定可用无人机机时U_t。逐期复用第二题最大化100Σw_i s_i,t，计算最高可达服务分、重点底线及缺口。

该结果假设同一编制允许各期重新配置，是规划服务曲线，不是实际观测。若锁定第二题某个固定部署，应另算并明确，不能与逐期重优化曲线混称一条结果。目标点不可达或硬性底线在预算内无解时，报告原因，不降低要求制造达标。

## 4. 固定目标，反求最省人时配置

全年保持同一目标η和重点底线。80分/重点0.90仅是示例，尚非已定标准。η不能逐月下降迁就资源。

变量仍为地面监测人时x_i,t、无人机机时h_i,t和合格服务完成率s_i,t。每期求：

min H_req,t = Σ_i x_i,t + γΣ_i h_i,t + H_0,t

约束：

- C_i,t s_i,t ≤ c_i^g x_i,t + c_i^u h_i,t，0≤s_i,t≤1。
- 100Σ_i w_i s_i,t≥η，Σw_i=1且评价范围完整。
- 重点对象最低服务、地面不可替代工作和固定基本响应条件满足。
- Σ_i h_i,t≤U_t；无人机不适用的服务不能用h替代。

C是预先规定的服务数量，c由路线、队伍人数、飞行及停留时间计算，不是减损拟合。γ为每机时配套操作、准备及审核人时；H_0保留共享基本响应和其他明确必要地面工作。所有工时需去重。

采用scipy.optimize.linprog(method='highs')。第三题重新选择地面/无人机组合，不能把第二题追求最高分的方案直接相除后称维持较低目标最省人。既不重新引入固定资源配比，也不建详细整数轮班。

## 5. 人时换算规划人数

每期N_t=ceil(H_req,t/q_t)；全年固定人数初估N_plan=max_t N_t，各月人数不相加。

演示假设：常规期3600人时、单人120小时，则30人；重点期4800人时、同样120小时，则40人。例子不代表埃托沙实算。

q只扣除休假、培训、行政等未计入服务需求的不可投入保护时间。出行和无人机准备已计入x、γ时，不能再从q扣一次。题目295人是部门工作人员参考总数，不能直接当295名可用巡护人员。

最后做基本同时在岗检查：驻点响应人员、飞手是否足够，同一人是否被同时重复使用。月均人时不能证明排班可行，未通过应修正估计；结果称给定条件下的规划人数，不称严格最低可行编制。当前不开展详细排班。

## 6. 最少新增参数与输出

相对第二题主要新增目标η、单人有效工时q和少量有依据的季节服务规则。各区价值、服务率、路线、设备和基本响应继续复用第二题，其参数尚未填齐时不能给出真实人数。

输出时期表：服务需求、固定资源下服务分、重点底线、维持目标所需人时、规划人数和缺口；配保护服务与人员需求的时间曲线。第四题再改变目标、有效工时、机时和季节规则检验稳定性。
