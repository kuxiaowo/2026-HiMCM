# 第三题：保护服务随时间变化与人力需求估算

> **本轮已完成：**基于第二题599点、17区和原成本，采用基准目标η=57.26016128。中档季节方案全年峰值57人，异常干旱运维加密峰值62人；初算、图表、数据证据和核验见[第三题模型实算](第三题模型实算.md)。保留γ_j=o_j/b_j、0≤s_j≤r_j及共享响应H_0，不采用原80分例子。

更新：2026-10-06。模型初算已实施；[正式写作框架](paper/question3_framework.md)已压缩为5个二级、13个三级标题，每节最多三个，原3.7分析评价归第四、五题。沿用独立人时/机时LP，不预测动物数量或事故，不建立详细轮班MILP。第二题原结果保持；第三题增加17处历史人工钻井样本运维及季节火险筛查，不计算SPI或运水体积。

## 1. 原题要求及与第二题的关系

原题第三项要求分析公园随时间受到多好保护，并估计维持所选保护水平所需人员。只给一个人数不足以完成第三题。

| 分工 | 给定什么 | 求什么 |
|---|---|---|
| 第二题 | 人时、设备、服务标准 | 最高需求加权服务完成分及资源配置 |
| 第三题：时间分析 | 同样人员与设备，分期服务需求 | 各期可达服务分、重点底线和缺口 |
| 第三题：人员需求 | 目标服务分、设备和标准 | 达到目标最省人时的配置，再换算规划人数 |

评分表达规划服务能力，不是实际生态保护成功率。基本响应条件及重点底线必须另检查。

## 2. 时间维度：先两个代表时期，再展开月份

按12个标准30天月求解。研究采用旱季5—10月、湿季11—4月；官方Etosha火管理窗口为5—7月早期、8—11月重点期。时间窗口有资料，具体加密频次和现场耗时则为低中高规划假设。

- 价值、路网、基准需求权重w_i第一版固定，不另建动物迁移和数量预测；统一权重便于跨期比较。
- 基准巡查频次不变；额外火险筛查用单独y/v变量和任务约束，与基准共用机时预算。中档每100km²可燃生境每月额外2/4点次，只要求原可响应范围，未可响应范围单列未保障。筛查不代表实际扑救或计划燃烧。
- 17处BH钻井必须地面运维，中档湿季2次/月、旱季4次/月，异常干旱压力8次/月；平时现场0.5小时、压力下1小时。天然泉不计抽水设备运维，完整当前水点清单仍缺。
- 无季节日志时，单位作业时间和无人机可用机时固定；设备停用、道路封闭等变化放第四题情景。
- 单人有效保护工时按用户决定固定120小时/月，不另扣节假日等；基本响应固定2880人时，共享驻点只计一次。

若需求、权重、设备和有效人时都不变，各期结果相同是合理结论，不能人为改参数制造变化。没有实际部署时序时，不能声称回测历史保护或人员变化。

## 3. 固定资源，先算各期保护服务

给定假设保护人员N_0=59，该期预算H_t=120N_0；无人机U=240。扣除水点必要地面工作及额外火险检查，同期重新配置基准监测、最大化100Σw_j s_j,t。中档全年保持57.26分；异常干旱加密时8—10月降至54.97分。

该结果假设同一编制允许各期重新配置，是规划服务曲线，不是实际观测。若锁定第二题某个固定部署，应另算并明确，不能与逐期重优化曲线混称一条结果。目标点不可达或硬性底线在预算内无解时，报告原因，不降低要求制造达标。

## 4. 固定目标，反求最省人时配置

全年保持同一目标η=P_2*=57.26016128及原区域可达部分15%通用底线。目标来自第二题最优服务的延续，不等于已测得生态成效；不可逐月降低目标迁就资源。

变量为基准监测人时x_j,t、机时h_j,t、完成率s_j,t；新增火险人时y_j,t、机时v_j,t。W_t按水点频次乘每次路网往返/现场/准备人时预先计算。每期求：

min H_req,t = Σ_j(x_j,t+γ_j h_j,t+y_j,t+γ_j v_j,t)+H_0+W_t

约束：

- C_j s_j,t≤x_j,t/a_j+h_j,t/b_j，0≤s_j,t≤r_j。
- D_j,t≤y_j,t/a_j+v_j,t/b_j，D_j,t=k_t A_j^fuel r_j/100。
- 100Σ_j w_j s_j,t≥η，Σw_j=1；保留原区域底线。
- Σ_j(h_j,t+v_j,t)≤240；不适用无人机的任务机时为0，水点W_t全部是地面人时。

C是原规定服务数量，a/b/γ由第二题路线、队伍人数、观察协议和机时计算，不是减损拟合。H_0共享响应仅计一次，新增任务采取独立往返、不合并路线抵扣，可能偏高；本轮未声称完整全园保障。

采用scipy.optimize.linprog(method='highs')。第三题重新选择地面/无人机组合，不能把第二题追求最高分的方案直接相除后称维持较低目标最省人。既不重新引入固定资源配比，也不建详细整数轮班。

## 5. 人时换算规划人数

每期N_t=ceil(H_req,t/q_t)；全年固定人数初估N_plan=max_t N_t，各月人数不相加。

本次中档实算：常规月5497.28人时/46人，5—7月6270.14/53人，8—10月6831.83/57人，11月6620.66/56人。全年固定57人；异常干旱压力峰值7390.17/62人。人数针对指定服务与17处历史样本，不是实测编制。

q固定120，不另做扣除。出行与准备已计入需求人时。题目295人是部门工作人员参考总数，第二题采用20%参与保护岗位的假设，不能直接当295名巡护人员，也不据此建议现实裁员。

最后做基本同时在岗检查：驻点响应人员、飞手是否足够，同一人是否被同时重复使用。月均人时不能证明排班可行，未通过应修正估计；结果称给定条件下的规划人数，不称严格最低可行编制。当前不开展详细排班。
