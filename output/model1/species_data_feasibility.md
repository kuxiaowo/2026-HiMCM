# 物种数量、密度与法定权重的数据可行性核查

核查日期：2026-10-05。研究对象：埃托沙国家公园。这里核查的是区域价值指标的数据基础，尚未运行资源配置优化或校准保护效能。

## 1. 结论与采用范围

“区域物种数量/密度 + 法定保护类别”可以形成有实际数据支撑的动物保护价值指标。已取得2015年航空调查原始报告，包含15个统计单元、11类大型动物的分区表；已取得较新的法规汇编，能匹配主要候选物种的保护类别。

第一版建议选非洲草原象、长颈鹿、平原斑马、南非剑羚、蓝角马、鸵鸟6类动物，用2015年旱季调查建立历史分区示范模型。哈特曼山斑马可作为补充。黑犀牛、跳羚、红狷羚和Eland保留在原始底表中，但存在不同程度的来源矛盾或待核对项，不默认进入主方案。

这足以验证指标结构和分配方法，不能直接代表2026年的实际种群分布，也不能宣称覆盖全部动植物。黑犀牛等重要物种在数量核验前，应以重点栖息地或明确标记的补充情景保留其作用，不能因为暂缓数量表而认定价值为零。植物先用已确认分布和栖息地面积独立评价。主盐沼不在动物调查范围内，需要独立的鸟类/栖息地分项。

## 2. 已实际取得的动物调查数据

- 调查日期：2015-09-04至2015-09-21，旱季。
- 调查范围：18,551.14 km²，报告明确不包括主盐沼。

## 3. 数据质量问题：原表保留，不自行修正

已渲染并目视核对调查报告第5-12、16页以及法律相关附表。以下异常确实出现在原PDF中。

1. **跳羚ENP6**：目击18、区间下限18，但估计数11，上限236；不能自行把11补为111。该物种分区数量之和虽然与总计10,317一致，也不能证明这一异常值正确。ENP16的数量1,027除面积918.1365约为1.119个/km²，而表格密度印为2.32；密度不得原样使用。
2. **蓝角马ENP15**：CI百分比印为6,327%，与估计903及半宽571不符；保留数量与原区间，忽略该错误百分比。根据印出的571/903重算约63.23%可作为派生字段，不能冒充原始准确值。
3. **黑犀牛**：第3页1.6称因安全原因不在报告中列出黑犀牛数据，但表2、表6以及图标题实际存在。表6有数分区的估计合计1,107，与总计1,280相差173，超出普通整数取整差异。此前“没有取得黑犀牛数量数据”的说法应修正为“取得了有内部矛盾的历史候选数据，需要核验”。
4. **Eland**：表2总计1,321，表13总计1,103，表13有数分区合计928；不能任选一个作为全园一致底表。
5. **其他抽样扩展疑点**：红狷羚ENP7目击14、估计22，与对应搜索比例下的简单扩展值约45相差较大；南非剑羚ENP1目击27、估计640也存在明显疑点。简单扩展比不是对Jolly方法2的重算，仅用于定位需要原始调查记录解释的条目。南非剑羚的分区估计之和与总计4,108一致，但不能据此认定每个原始字段无误。
6. **空白与零**：很多行数量空白，仅密度0.00；哈特曼山斑马多区连密度也空白。必须区分有数估计、调查未检出、源表空白、调查范围之外。没有观察到不等于生态学上不存在。

大象、长颈鹿、平原斑马、剑羚、蓝角马、鸵鸟的有数分区估计之和分别与各自报告总计一致。此检查仅证明内部加总一致，不能替代调查精度与时效核验。部分分区置信区间较宽，因此区域优先级应做区间/情景检验。

## 4. 法规能否决定每种物种的价值权重

已取得国家贸易门户发布的84页注释版《Nature Conservation Ordinance 4 of 1975》，以及FAOLEX的77页汇编（标记截至2017-06-28，PDF生成2025-07-29）。新版比之前主管部门网站的截至2003年旧汇编更适合分类，不能仅根据下载或生成日期认定法规已更新到2026年。

- 附表3：特别保护动物，包括候选的大象、长颈鹿、平原斑马、山斑马、犀牛。
- 附表4：保护动物，包括蓝角马、红狷羚、Eland及狮、豹、猎豹等；附表4(ii)涉及鸟类，需要与附表6和其列明例外联合判断，鸵鸟未被排除。
- 附表5：可猎类，包括南非剑羚、跳羚。
- 附表9：保护植物，包括Moringa ovalifolia、芦荟属等。某植物出现在全国法律名单上，并不证明它在埃托沙每个分区存在。

这些名单能提供分类依据，**没有提供“每只大象值多少分、每只斑马值多少分”的法定生态价值表**。可先按类别共享3、2、1作为建模情景，不给每个物种拟合独立自由参数；比较其他相对权重，检验排序与资源配置是否稳定。

法律保护类别与濒危等级分别记录。特别保护个体占比可以计算；“濒危物种个体占比”需要另加可靠濒危名录并匹配分类尺度。由6种动物计算的占比只能称“选定物种中的占比”，不能称整个公园全部动植物的占比。

检索还发现2026年GN115（公报8877号），索引原文涉及入园收费修订；本地全文未成功取得。这不提供物种生态价值比，也不能据此宣称已完成2026年所有修订核查。

## 5. 珍稀植物与较新数据的可得性

主管部门公园介绍明确列出Fairytale Forest的Moringa ovalifolia，以及主要植被类型。2016年原始研究说明在公园Halali采集过M. ovalifolia种子，2020年物种边界研究也涉及Halali和Sprokieswoud。这些材料能支持出现与分布地点，不能把研究采样数量当该地区植物总量。

本次没有取得可核验的全园15分区植物株数/密度表。第一版使用“已确认分布区域 + 对应栖息地覆盖面积”更现实。用遥感计算植被覆盖可行，但土地覆盖产品不能自动识别珍稀植物；GBIF/iNaturalist记录数也不能直接充当个体数量或密度。

2025年纳米比亚提交CITES的CoP20 Prop.13在可检索的正文和参考文献中引用了2023年的埃托沙航空调查，说明存在较新的官方调查线索。该CITES PDF直接下载返回403，本次也未取得2023年原始分区报告；因此没有把网上较新总量或新闻数字代入分区底表。不能把2015年数据称作“最新”。

狮、豹、猎豹等存在监测研究与更新调查项目，但本次未获得与2015年15统计单元统一、完整、可直接汇总的数量矩阵。不要求所有物种齐全，也不因此把这些重要物种的区域价值设为零；有可靠出现信息时可作重点栖息地补充。

## 6. 预处理与进入模型的具体方式

### 6.1 最小数据表

原始长表保存：统计单元、物种代码/学名、估计数量、目击数量、95%区间上下限、调查面积、原表密度、由数量重算密度、年份、季节、来源页、质量标记。权重表另保存：物种、法定类别、附表、版本、候选权重、建模赋值标记。

已生成`species_region_counts_2015.json`，含15个统计单元、11类物种、165条区域-物种记录。原表数值完整保留，有疑点物种的`recommended_core_input`为false。`candidate_baseline_count`只是供试算的候选值，不是2026年事实。

### 6.2 数量、密度与缺失处理

1. 同一轮2015年旱季数据优先，避免混用不同年份与调查方法后当作同一时点。引用较新法规时注明这是以所选汇编中的管理类别评价历史分布的规划试算，并说明法规版本。
2. 首选报告估计数量。密度由估计数量除对应分区面积重算，避免使用粗略四舍五入或有错的原密度反推数量；数量和密度不同时作为两项重复加分。
3. 有数估计直接保存；明确调查未检出的零保留“未检出”标记；数量空白但原表密度0.00的已调查分区，可在基准试算中显式假设为0，同时检查未检出情景。整个空白行和调查外范围保留null，不能自动填0。
4. 黑犀牛、Eland等冲突数据不靠插值或归一化掩盖，先隔离；个别错误百分比可舍弃，因为主模型不依赖该字段。数据缺失不能等同于生态价值为零。
5. 置信区间用于判断排序与配置是否稳健。逐区采用上下限构造的是情景，不是全园联合95%置信区间；相加的各区下限/上限也不能直接当全园统计区间。

### 6.3 推荐的数量归一化与法律加权

单纯“数量乘3、2、1后求和”有一个实际问题：按上述6类动物试算，全园加权数量80,857，平原斑马贡献42,696，占52.8%。这反映它的数量多，不足以说明它应该获得过半保护资源。

推荐先对每个物种计算“该区数量 / 该物种同一调查范围内的总数量”，再按法定类别加权。这样保留动物在园内的空间分布，也减少不同物种自然种群规模差异导致的主导。其解释是区域对各物种的相对保护责任，不是法律规定的每个个体价值。

同时保留原始数量与单位面积价值作为解释字段。若团队明确要保护更多个体，可以把直接加权数量作为对照方案。重点保护个体占比适合作为解释或底线，不宜与已加权数量重复加分。

例：ENP1面积1,728.118 km²，大象估计405、长颈鹿578、平原斑马3,043；ENP17面积921.1887 km²，对应448、464、730。已经能在真实分区上计算区域总保护责任与集中程度，而无需收集个体轨迹。6物种直接加权数量的演示值分别为15,444和5,640，仅演示数据链条，不是最终生态评分。

### 6.4 分区、栖息地和资源分配衔接

- 第一版采用原15统计单元作为动物数据支撑尺度。已取得AED公开概化坐标，依据报告图修复重叠、裁界，并加入主盐沼近似区和其他调查外残余，共17个空间单元；最终GeoJSON在`data/regions/processed/model_regions.geojson`。WorldCover比例已计算，水源/道路风险/过火指标尚待叠置。历史动物密度仍用原报告面积；165条原始行在`output/regions/species_region_link_2015.csv`无损保留，补充区域动物数量为null。
- 如重新按生态环境划区，需要把调查单元与新分区叠置。按重叠面积或适宜生境比例分配原单元数量属于显式假设，不能声称得到新分区实测密度；合并调查单元也不能无依据独立拆估。
- 主盐沼独立保留；植物/栖息地分项先独立归一化，再与动物分项合成。植物株数、动物个体数和栖息地面积不能直接相加。
- 动物价值与威胁、响应时间、人员/设备投入进入既定直接分配模型；此处的数据证明价值指标可计算，尚不证明投入能降低多少实际损失。
- 园内份额归一化后的动物责任分数在全园求和固定，不能用其求和增减衡量成效。成效阶段须使用固定基准下的剩余风险/损失变化、物种数量变化或栖息地改善，另行校准。

## 7. 当前可行性判断

| 子任务 | 判断 | 完成条件或限制 |
|---|---|---|
| 代表性动物的历史分区数量/密度 | 可行 | 已取得表格；采用质量筛选后的6类动物，处理未检出与不确定性 |
| 主要候选动物的法定类别 | 可行 | 已取得并核对附表；旧学名匹配和2026完整修订检查仍需注明 |
| 法律直接给出数值生态权重 | 不成立 | 数字比例由模型设定并做敏感性分析 |
| 全园珍稀植物精确数量/密度 | 当前材料不足 | 可改用确认分布与栖息地面积，不能把出现记录当密度 |
| 新生态分区的实测数量矩阵 | 当前没有 | 需原GIS/数字化及空间重分配假设 |
| 2026年全部动植物的精细网格密度 | 当前材料不支持 | 需要新的统一调查或可信模型，不以旧数据冒充 |
| 以这些数据实证预测资源投入的保护效果 | 尚不支持 | 需要历史投入、事件/损失、对照与调查努力等另外的数据 |
