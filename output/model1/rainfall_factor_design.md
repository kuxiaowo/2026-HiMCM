# 月降水数据与降水因子设计

日期：2026-10-05。用户确认已有50年逐月记录，并提供GPCC V2025、0.25°全球格网的1971—1975年样例；已实际读取并提取17区60个月平均降水深度，完整50年尚未拼接核验，SPI未计算。原“只有12个月均值”的条件已更新。最新设计见[50年降水指标](../../docs/降水指标设计.md)，样例见[检查说明](../rainfall/GPCC示例文件检查.md)。雨季SPI-6生成一个主不足指标，距平仅解释、短期指标仅辅助。本说明保留距平和来源核查，不扩展逐日模型。

## 1. 第一版采用决定

新增一个带时间的主环境指标δ_i,y，由最近完整雨季SPI-6生成。保留雨季距平R_i,y解释少雨比例，但不与SPI/δ作为独立风险项重复加权；SPI拟合的是降水分布，不是资源投入的减损效果。

从完整逐月表计算12个月气候均值，用于确认季节，再使用各年的原始累计量计算异常。50年记录能够支持历史降水分布估计，但需检查连续性、有效雨季数和来源同质性。

## 2. 当前数据如何使用

先确认原表每个数是该年该月的累计降水深度（mm），而不是日平均雨量、降水率或其他单位。确认参考时期和空间范围，检查缺月及来源变化。

根据12个月均值检查雨季集中在哪些月份。第一版暂按11月至次年4月定义完整雨季，评价年y的雨季为y-1年11、12月与y年1-4月。这个窗口须由现有季节曲线核对，不能仅因指数名为SPI-6就任意选择六个月。

长期平均雨季降水为：

`mean_wet_rain_i = mean_P_i,11 + mean_P_i,12 + mean_P_i,1 + mean_P_i,2 + mean_P_i,3 + mean_P_i,4`

从逐月原表提取评价年份同一雨季的6个月累计雨量，得到wet_rain_i,y。窗口不完整时保持缺失，不补零。

距平率定义为：

`R_i,y = (wet_rain_i,y - mean_wet_rain_i) / mean_wet_rain_i`

R=0表示等于长期平均，R<0表示偏少，R>0表示偏多。例如以下是假设演示：长期平均雨季400 mm，目标雨季280 mm，R=-0.30，表示比基准少30%，不是干旱发生概率30%。均值为0时不可相除，应换适当时窗或标记不适用。

需要0-1的降水不足量时，可由同一R派生`D_i,y=max(0,-R_i,y)`；在雨季总量非负且基准大于0时D位于0-1。D只表示相对降水不足，不表示水点断供率、动物死亡率或火灾概率。保留带正负号的R，避免丢失湿年信息。

## 3. 完整逐月资料的处理

最小底表记录区域或站点/格网位置、年份、月份、月累计雨量、来源版本、参考时期、质量和缺失标记。

1. 统一为mm/month，检查负值、重复月份、异常大值和缺失；真实0保留。负值先核对填充值或产品误差，不机械将所有负值截成0。
2. 格网降水为深度，先以像元与区域的重叠面积做区域面积加权平均，再按月份累加。不能将一个区域内所有像元的mm相加，也不能将某站观测直接称全区实测。
3. 雨季月份缺失时不补0，先获取原始值；无法补齐的该年度累计标记缺失。若采用插补，须保存估计标记及方法并检验影响。
4. 基准和评价雨量优先来自同一来源、同一版本和同一空间统计方式。若新下载格网与现有站点50年均值不匹配，重新从格网计算相应基准，原表作为外部对照。
5. 在逐月资料中计算各年同一雨季总量。若获取1976-2025年月序列，要计算1976年4月底的完整雨季，还需1975年11-12月；首个不完整窗口不能充作完整雨季。
6. 固定基准期，用同一尺度比较配置前后。用于事件前回测时，基准拟合和参数校准不使用预测时点之后的观测；以全时段描述历史变化时说明这是回顾性统计。

SPI-6的正式计算针对相同结束月份的6个月累计序列分别拟合降水分布，并处理零降水概率，再转换到标准正态尺度。它不只是直接计算“减平均再除标准差”。例如每年4月底的SPI-6只比较历年11月至4月的累计量，不将不同季节的6个月量混合拟合。拟合分布需检查适用性；Gamma或其他已验证方法可用，不凭12个多年均值估计分布。

SPI比较的是相对于当地历史气候的异常，不是不同区域的绝对湿润程度。不能将每区长期平均SPI作为空间水源丰度指数。长期空间供水背景可用原始平均雨季雨量描述，年度异常R/SPI用于年景修正。

## 4. 如何参与当前模型

水源侧：R<0增加降水不足情景压力，结合W_i与季节/天然水源依赖进行解释；人工井、水泵可用性仍由运行状态确定，不能根据R直接判定断供。没有水位、流量与供水记录时，不声称已得到实际可用水量或长期水文干旱。

火灾侧：前一雨季雨量影响植被生长和后续燃料；干季干燥影响燃烧，但极端少雨又可能限制燃料形成。因此不预设“R越低，火风险一定越高”，也不直接将D加到火风险总分。

已有F_i是多年历史火暴露，SPI/R是评价年景的信息。完成降水及逐年过火处理后，检查雨季指标与随后晚旱季过火率的关系；若关系不稳定，保留年景解释和情景，不直接修正火权重。降水影响的方向和幅度尚未校准，不能从降水指标本身推导。

保护资源不改变降雨。巡护、监测效能仍作用于发现和响应；不据此声称人员投入能消除气象干旱。

若只有全园一套雨量，采用全园共用R_y，不伪造各区域雨量差异。取得覆盖公园的格网或多站资料后，才生成区域R_i,y。固定多年部署时，采用不同年景情景比较稳健性，而不是把多年R/SPI求平均后当作风险指标。

## 5. 数据来源选择与核查范围

- 优先候选：[CHIRPS v3](https://www.chc.ucsb.edu/data/chirps3)，1981年至接近当前、0.05°格网，提供月度正式产品。1981-2025包含45个完整公历年，足以支持常用长基准计算，但不应称作50年。当前只核对官方产品说明，未下载本园全期降水。
- 若必须覆盖完整50年，可选[ERA5-Land月度资料](https://www.ecmwf.int/en/forecasts/datasets/era5-land-monthly-averaged-data-1950-present)，覆盖1950年以来；它是再分析数据，不能称每个区域均有实测雨量站。
- [Earth Engine ERA5-Land MONTHLY_AGGR](https://developers.google.com/earth-engine/datasets/catalog/ECMWF_ERA5_LAND_MONTHLY_AGGR)中的`total_precipitation_sum`为月累计深度、单位m，转换到mm需乘1000。该平台月累计与CDS月平均产品的聚合方式不同，CDS月平均不能不看文档就直接当月累计；根据产品说明转换，避免再乘或漏乘月天数。
- [WMO/GWP的SPI说明](https://www.droughtmanagement.info/standardized-precipitation-index-spi/)建议理想记录不少于30年，并说明SPI只使用降水，不能完整反映温度、蒸散和水文供水。
- [NDMC的SPI时间尺度说明](https://drought.unl.edu/Monitoring/SPI/MapInterpretation.aspx)明确SPI-6比较相同6个月窗口的历史累计。
- [埃托沙原始火管理研究](https://koedoe.co.za/index.php/koedoe/article/view/264/0)将季节降雨与距上次燃烧、草本燃料等共同用于火管理决策。

当前最少主模型字段为SPI派生的`δ_i,y`，作用于有依据的水源检查工作需求。原SPI、距平、累计量、长期基准、完整性与年份保存，不全部独立加权。实际执行及资源接口以[最新设计](../../docs/降水指标设计.md)为准。
