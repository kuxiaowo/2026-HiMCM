# 火灾数据如何进入分区资源模型

日期：2026-10-05。状态：核对NASA MCD64A1 Collection 6.1用户指南的相关完整页面；核对本地瓦片的长期目录；下载并检查2022年9月的一份Burn_Date和QA栅格。尚未完成全期下载、全期QA检查、分区裁切与区域指标计算。本说明提出可执行处理方案，不是已经拟合或验证的火灾预测模型。

## 1. 当前采用决定

偷猎侧按用户决定复用道路图的最短通行时间算法，形成道路进入便利度情景。巡护响应采用同一算法，但起点是保护驻点，不能把两个时间混为一项。现有`build_network.py`完成了候选路网构建及方向/权限属性保留，尚未实现完整的通行时间计算。

火灾侧第一版只采用一个核心输入：**多年平均晚旱季过火比例**。它描述过去的空间燃烧暴露，作为相对火管理需求的依据；它不是起火概率、火势强度、生态损失率或人员投入的实证效果。

植被类别只用于确定潜在可燃生境和受影响价值，不再给火灾增加一组自由权重；最近燃烧状态可以从同一数据提取，但不进入第一版主评分。逐日风速、湿度、燃料含水量、动物取食和起火原因暂不输入，采用固定评价季节、管理条件大致可比的战略配置情景。

## 2. 已核实的数据条件

产品为MCD64A1 v6.1，名义500 m、月度。原生MODIS正弦网格的像元边长约463.3127 m；实际面积计算使用栅格地理变换或等面积相交，不能将每像元固定当作0.25 km²。

NASA原始HDF中：Burn Date=1至366表示大致燃烧日序，0表示未烧陆地，-1表示数据不足而未制图，-2表示水体。QA的bit 0区分陆地/水体，bit 1表示有效观测是否足够，bit 2表示该月可靠制图期是否缩短，bits 5-7记录某些直接归为未烧的特殊条件；bit 3的上下文重标记不等于质量失败。

本次抽查Planetary Computer的2022年9月h19v10转换栅格，确实保留了Burn_Date的-2、-1、0和正日期值，GDAL nodata为-1。正燃烧日期均对应有效陆地QA。Pillow解码数组的int32不代表原文件储存类型；该TIFF为16位有符号整数，目录声明int16。QA为8位整数，不能简单用QA>0表示有效数据，因为QA=1仍为数据不足陆地。

目录结果：

- Planetary Computer的2001-2025当地瓦片检索得到292个不同月份，2001-2022年各12个月；其后缺2023-09、2024-07及2025年的6个月。这只是该镜像目录的缺失。
- NASA CMR对2016-2025年同一h19v10瓦片返回120个条目、120个不同月份，每年12个月，没有目录缺月。因此近十年窗口在原始目录层面可行。
- NASA CMR只核对元数据，未完成这些HDF的认证下载，也未证明每个月每个像元都可用。可从NASA原始产品补齐镜像缺月，或统一从原始产品处理，不能补零。

默认采用2016-2025年作为2026规划的火灾历史窗口；若模型被设为2015历史案例，则改用截至2015评价时点之前的窗口，不能引入未来火灾。2015动物数量、2021土地覆盖、2026道路若合用，应明确是以不同年份资料构建的静态演示，不能称2026实测状态。

## 3. 栅格到区域指标

1. 已完成与15个动物统计单元一致的公开概化边界修复，另保留主盐沼近似区和其他调查外残余，共17个空间单元，见`data/regions/processed/model_regions.geojson`。ENP3410仍为合并统计。该边界不是已验证的官方原GIS；ENP8/9面积偏差较大，空间火指标需保留边界敏感性。生态类型与可燃生境近似面积已在`output/regions/ecology/region_ecology.csv`按区计算；历史过火分数尚未生成。
2. 将WorldCover林地、灌丛、草地等合并为潜在可燃生境C_i，排除确认的主盐沼、开阔水面与明显无植被地表。林地类别是否有连续草本燃料并未由WorldCover证明；这个合并是第一版生境近似，比较“草地/灌丛”和“含林地”的掩膜情景。
3. 将10 m类别汇总为每个MODIS像元内的可燃面积份额，再统计区域相交面积。不要把500 m火灾图上采样到10 m后声称得到10 m火灾精度。
4. 读取Burn_Date和QA。基准采用陆地且有效、制图期未缩短的像元；未烧像元同时排除特殊条件码非零的记录。这是一项保守的团队质控规则，不是NASA规定的唯一筛选方式。已有燃烧记录与未能确认的月份分别保存，不能因另一个月份缺测就删除所有已知燃烧证据。
5. 按产品年份将正日序转换为实际日期。基准季节选9-10月，因为本园研究发现火活动主要集中于这两个月；季节选择用于聚焦管理暴露，并不证明这两个月所有燃烧都属于有害野火。将8-10月和5-10月作为季节敏感性比较。
6. 在每年目标季节内对过火像元取并集，同一像元在该年该季节只计一次。不同年份再次烧过则各年分别计入；本指标统计面积暴露，不统计独立火灾事件次数或同年重复燃烧次数。
7. 基准区域年度比率只在目标季节各月均可靠的可燃区域范围内计算。分子和分母采用同一范围；在全可燃范围内已观测到的过火面积另存为已知下界，避免丢弃证据。保存可靠范围占C_i的比例；默认至少90%才接受该区域年度比率，比较80%与95%。阈值是模型质控选择，不是通用统计标准。
8. 目录缺月优先补齐。空间覆盖不足的区域-年份记录为缺失，不设为0；所有区域尽量使用相同保留年份。若各年的可靠空间范围变化明显，另用共同可靠掩膜复算，检查空间采样变化是否影响排序。

计算年度值h_i,y：

`h_i,y = 该年目标季节可靠可燃范围内的去重过火面积 / 同一可靠可燃范围面积`

在通过质控的共同年份内取算术平均，得到H_i。它既考虑各年的过火范围，也体现跨年重复暴露。不再同时加入“历史火灾频率”和“累计过火面积”并独立加权，以免对同一信息重复加分。

H_i本身在0-1之间。若为了和道路便利度统一为相对强弱，可使用基准区域最大值进行缩放：`F_i=H_i/max(H)`。保留原始H_i，并固定缩放基准，不在方案部署前后分别重新归一化。若基准所有H_i为0，则无法从该数据区分区域，不进行除零、不宣称风险为零。

建议区域底表只保留以下核心派生字段；质控字段不作为风险因子加权：

| 字段 | 用途 |
|---|---|
| `region_id` | 与动物、道路及资源表关联 |
| `combustible_area_km2` | 过火比例统计范围 |
| `mean_late_season_burn_fraction`（H_i） | 核心历史过火暴露 |
| `fire_exposure_index`（F_i） | 固定尺度下的相对暴露 |
| `valid_years`、`valid_coverage_min` | 质控与结果可比性 |
| `recent_burn_fraction`（可选） | 近期状态解释和敏感性分析 |

## 4. 如何参与资源直接分配

先确定区域中会受火影响的保护价值V_i^F。优先关注植物和栖息地，以及动物依赖的生境；动物数量多不能直接等同于火会造成相同数量的动物死亡。

若只有区域总价值而没有精确空间分布，可以在区域内采用统一价值密度的简化，将其中可燃范围对应的价值作为V_i^F。这是显式空间分摊假设；若采用动物适宜生境分配，应改在适宜生境内分摊，不能把同一份价值重复分配。盐沼在火灾分项中的低暴露不代表其全园生态价值为零。

形成未部署方案前的相对火保护需求：`D_i^F=F_i × V_i^F`。F_i不包含真实有害比例或损失程度。若需要构造有害性情景，使用一个全园统一的损害系数，并比较低/中/高情景；该系数是模型假设，无法从Burn_Date直接估计。

不要在D_i^F外再乘一次可燃面积比例；若它已用于确定V_i^F，再乘会重复削减。若V_i^F已经是区域总价值，不再另乘区域面积。

保护人员、监测投入和驻点到区域的最短响应时间共同决定假定的处置改善。监测可以缩短发现延迟，响应队伍仍需实际到达及处置；投入不应直接改变历史H_i。响应时间用于资源作用机制，不自动作为火灾发生率加分项。

比较同预算的均匀分配、现有部署（若取得）和优化方案的剩余风险指数。历史火活动包含既有保护和计划烧除效果，不能把历史H_i当作无人管理基线后重复扣减既有资源效果。没有资源-效果记录时，报告情景下的模型改善，不能声称已经验证实际减损率。

## 5. 最近燃烧、降雨和成效评价

最近燃烧可减少短期燃料，但恢复受降雨、植被和取食影响；多年未烧也可能是低可燃性，不能按火龄一律递增风险。第一版先不把火龄加入主公式，保留近期烧过比例并检查核心排序对近期状态是否敏感。观察期内从未检出火的像元仅知道火龄下界，缺月也会影响火龄可靠性。

采用多年平均并没有“消除”降雨、燃料和计划烧除的影响，而是将共同作用下的历史暴露作为战略规划参照。用户最新确认已有50年逐月降水，实际文件未收到。最新方案用雨季SPI-6派生不足指标处理水源检查工作，原SPI/距平解释火年景；火暴露不直接乘降水不足量。需与同年随后晚旱季过火配对检验，50年雨量不代表50年火—雨配对。关系不稳定时保留情景解释，不预设少雨必然火多。处理见`rainfall_factor_design.md`及`docs/降水指标设计.md`，未完成扩展关系拟合。

第一版成效采用**同一火情和气象情景、同一价值与尺度下的剩余风险指数下降**，辅以重点区域的发现/响应时间和有效覆盖。若取得实测数据，优先考察非计划有害火影响的重点生境面积、受损保护价值和恢复；总过火面积下降本身不能证明保护成功，计划烧除可能降低后续危险。

种群价值下降通常意味着损失，不是保护有效。物种园内份额每次重新归一化后全园求和不变，不能拿这个值当恢复成效。预测过火面积的准确性与资源投入的减损效果需要分别验证；没有投入历史数据，不能从MODIS直接学出每增加一名人员的保护效能。

2026年9月NASA已发布本园当年新过火影像说明。若部署评价时点在该事件之后，要补充近期状态；若做事件前回测，则该事件只能用于留出检验。该新闻影像及其转述的初步面积不是完整分区统计，也不能与2015动物数量组合称作2026实测损失。
