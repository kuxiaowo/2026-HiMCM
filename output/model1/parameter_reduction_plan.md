# 模型一：参数精简与数据采用方案

最新题目分工见[整体建模计划](../../docs/整体建模计划.md)：第一题定义保护，第二题资源配置，第三题人力需求与排班可行性。此文件保留前期参数讨论；第三题已明确不采用预测模型。

日期：2026-10-05。状态：已取得并核对2015年航空调查的15统计单元、11类动物表格及法定分类汇编；已完成公开概化分区坐标的拓扑修复，形成15调查单元、主盐沼近似区、其他调查外残余共17个空间单元，并完成WorldCover 2021原生栅格逐区统计。尚未完成实际资源配置优化或实证效果校准，历史数量不能直接当作2026年现状。分区过程与论文方法见[过程记录](../../docs/modeling_process.md)、[分区方法](../../docs/paper/partition_methods.md)。

## 1. 采用范围

研究对象保持为整个埃托沙国家公园。以偷猎/非法进入和有害野火为两类主要威胁，以地面保护人时与无人机飞行小时为两类可调投入，保留道路通行和实际响应能力。卫星作为全园共享的信息来源，预留解译与核查人时；固定监测设备留作扩展，AI作用合并到发现效能与处理工时。区域价值优先由代表性物种的数量/密度和法定保护权重计算，并保留植物与栖息地价值分项；个体移动轨迹暂不纳入。设备台数与飞行小时不直接相加，技术通过发现、核查与人员响应产生改善，具体方案见`monitoring_technology_design.md`。

第一版输出相对保护需求、资源配置和模型内风险改善指数。未校准的评分不解释为真实动物死亡率或风险下降百分率。

按数据可用性与结构重要性分类：高重要且可取得的数据保留；高重要但难取得的数据用代理或显式假设保留其作用；被现有指标主要涵盖的驱动变量暂缓；次要运行细节合并到统一系数。这里的影响判断是结构判断，尚非数值敏感性结果。

## 4. 最少数据层与最终区域字段

保留五类核心空间数据：边界、道路及候选驻点、土地覆盖、水源位置/状态、历史燃烧。偷猎侧直接复用现有道路图，候选进入点由边界与路网确定；外部聚落不再是第一版必需层。地形高程是可选修正层。增加区域-物种数量表和物种-法定权重表，两表按物种学名关联；另有人员与监测资源上限这一张全局资源表。

按用户最新确认，已有50年月降水序列；采用格网时是第六类空间数据。空间范围尚未确认，不能制造区域差异。第一版只增加一个带年份的SPI派生降水指标，最新设计见`docs/降水指标设计.md`，来源与预处理见`rainfall_factor_design.md`。

最终每个区域保存下列派生量，加一个区域编号。新增的覆盖率、最近燃烧状态等主要从已有数据层计算，并不是新增一套自由效能参数。种群明细在关联长表保存：

| 字段 | 含义 | 得到方式 |
|---|---|---|
| `A_i` | 区域面积 | 从边界和分区直接计算 |
| `G_i` | 生态结构/适宜性特征 | WorldCover合并后的各类面积比例；盐沼和裸地结合地图区分。类型无统一价值高低排序 |
| `W_i` | 可靠水点覆盖率 | 评价季节内确认可用水点缓冲区的并集覆盖比例；半径为情景假设，未知运行状态单列 |
| `V_i` | 物种加权保护价值及植物/栖息地分项 | 由区域种群数量或密度与法律类别权重汇总；保留原始数量、加权数量、单位面积价值及重点保护占比 |
| `E_i` | 道路进入便利度情景 | 候选进入点到区域的多源最短通行时间转换；复用道路算法并明示权限假设，不是实测偷猎概率 |
| `F_i` | 多年平均晚旱季过火暴露 | 在可靠观测的潜在可燃生境内按年去重，计算过火比例并对共同有效年份取平均；用于主评分，保留原始比例和质控 |
| `R_i,y` | 前一雨季降水异常 | 同一雨季累计雨量相对长期基准的距平率；完整逐月数据到位后可用SPI-6替代，不同时加权。仅全园数据则共用R_y |
| `L_i`（可选） | 近期燃烧状态 | 同一Burn_Date提取近期烧过面积占比；不进入第一版主评分，只作解释和敏感性检查 |
| `T_bi` | 候选驻点到区域目标的时间 | 道路图最短通行时间加道路外连接时间；坡度/起伏优先作用于道路外通行，避免重复惩罚；不可达单列 |

`T_bi` 是矩阵，不是一个需要单独搜集的外部指标。区域数量表至少记录区域、物种学名、数量或密度、年份/季节、调查范围、方法、来源与实测/估计标记；权重表记录学名、法定类别、法规及修订版本、建模权重与依据。数量和密度换算时采用同一调查面积，物种出现记录不能直接当密度。

## 5. 简化假设与基准情景

下列数值只是建模初始情景，不是实测数据或生物学标准。

- 有效道路速度统一取 30 km/h，比较 20 和 40 km/h。保持已知单向约束；未确认权限的道路设置可通行/不可通行两个情景，不自动把所有路段当成巡护道路。
- 优先输入有来源的种群数量或密度；只在区域数据缺失时，以全园总量和适宜生境估计分布，并比较均匀与水源集中情景。水源代理不宣称能准确代表黑犀牛等物种密度；移动轨迹仍暂不输入。
- 物种按法律保护类别共享权重；可将 3、2、1 作为一种待检验的初始映射，但它不是法律规定的生态价值比例，也不能仅凭法律分类认定物种的濒危等级。国家保护策略或可靠濒危名录可用于补充区分。
- 生态类型优先保留面积比例；如转换为某物种适宜性或特定栖息地价值，需要另外的对应依据，不给林地、草地等统一高低排序。水源已用于估计动物分布时，不再给同一动物价值重复加分；盐沼不能直接赋零价值。
- 偷猎侧采用道路图多源Dijkstra，由候选进入点出发；巡护侧同一算法从驻点出发。道路与边界交点作为候选入口不代表实际非法通行许可，入口管控采用简化情景。区分进入时间与保护响应时间，未知通行条件不伪装成实测事实。
- 可靠水点覆盖可比较5、10、15 km半径，此范围不是所有动物的真实饮水活动半径；人工水点运行、季节水点旱季状态未知时，用可用/不可用情景，不伪造可用概率。
- 核心火灾指标采用2016-2025多年平均9-10月过火比例，比较8-10月及5-10月；历史案例按评价截点调整年份。NASA月条目已齐，仍需全期QA检查；缺失不补零。其含义是历史暴露，降雨、既有管理与计划烧除的影响未被消除。最近燃烧状态暂不独立加权；受损对象及严重程度另设假设，不能将全部火视为保护失败。
- 降水按前一完整雨季汇总，初设11月至次年4月并由现有季节曲线核对；使用固定基准的距平率，或资料完整后替换为SPI-6。基准与评价雨量保持来源、空间范围和单位一致。低雨量用于水源压力情景，火灾侧不预设低雨量必然高风险，须考虑雨季生长与后续燃料的关系。
- 驻点固定在地图可识别的少数候选营地。把旅游营地视为巡护后勤点是模型假设，不是实际巡护编制事实。
- 295 人作为部门工作人员参考总数。基准可假设 50% 能承担本模型的保护任务，比较 30%-70%。这是任务编制比例，不能当成同时在岗人数；按班次/有效工时换算资源上限，并包含监测操作与响应人员的消耗。
- 设备有效可用率基准取 0.8，比较 0.6-1.0；不分别建立维修、天气和每台设备差异模型。飞行小时计入往返，效能使用扣除往返后的有效监测小时；已纳入可用率的损失不重复折减。驻点固定，无人机可达性使用空中距离和续航，地面响应仍用道路时间。
- 威胁权重、价值等级和人员/监测作用系数全园统一。它们可能影响配置，必须做少量组合情景；没有资料支持时，不将系数解释为真实减损率。
- 第一版不模拟频繁并发事件，不预测长期种群增长、迁移或植被恢复。不采用天气预报级火情模型。

## 6. 数据如何进入直接分配模型

1. 区域种群数量与物种法定权重形成动物保护价值，优先使用报告估计数量，历史密度由其除对应的2015报告面积重算；不从粗略舍入或有错的密度反推数量，也不以概化GIS面积替换调查分母。空间统计另用修复后的几何面积，面积只计一次。植物采用数量、覆盖面积或分布等级独立形成分项，不把植物株数和动物个体数直接相加。`G_i`、`W_i`用于栖息地分项和缺失数据估计。
2. 本次按6类动物、类别权重3/2/1试算，平原斑马占直接加权数量的52.8%。第一版优先比较“各区数量占该物种同一调查范围总量的份额，再按类别加权”的相对保护责任，保留直接加权数量及单位面积价值作对照和解释。重点保护个体占比作为解释或底线；法律分类与濒危状态分别记录。6类物种的比例不能称全园全部动植物的比例。园内份额归一化后全园求和固定，不能以其求和变化作为成效指标。
3. `E_i`用于道路进入压力情景；`F_i`为唯一核心火暴露输入，`G_i`限定潜在可燃生境，`L_i`只作辅助检验。分别与受该威胁影响的对象价值结合。火需求采用`F_i × V_i^F`，若可燃面积已用于确定`V_i^F`，不能再乘一次面积比例；区域总价值也不再次乘区域面积。火的有害性与真实资源效能仍需另外依据。
4. 威胁代理是相对指数，不能称为实测事件概率。缺乏概率校准时，模型输出综合风险改善指数。

降水补充：R_i,y作为年度环境状态，用于水源压力和火情年景修正，不直接与F_i作为同义威胁重复加权。取得逐年过火和降水后再检查修正方向与幅度；目前仍是情景。保护资源不改变降雨，不能将巡护投入解释为气象干旱消除。

5. 地面保护人时x_i和无人机飞行小时h_i直接作为决策变量。飞行小时包括往返，满足机队可用机时与续航/作业范围约束。地面保护人时、无人机配套人时和卫星告警处理人时共同受总人力约束；固定角色和班次预留响应能力。同一人员不重复计入不同任务，发现威胁后仍需相应能力的队伍处置。
6. `T_bi` 与队伍可用条件进入响应效果。人员/监测作用采用少量全园统一系数，允许收益递减；不为每区设一套独立效能参数。
7. 计算部署后的剩余风险指数，选择总体改善较好且重点区域达到所选底线的方案。已有部署作为比较基准；历史风险受到既有保护影响，不能重复扣除。

第一版外部数据需求少，但用于预测效能的统一系数仍是高影响假设。直接按价值和威胁占比分配，不能代替对效能、响应和资源消耗的判断。

## 7. 精简后的检验规则

种群估计、法定类别的数值权重、分布假设、威胁权重、资源有效性与道路速度优先做敏感性检查。可将“全园指标变化不超过 5%、重点区域排序不改变、主要配置结构基本不变”设为初步保留/删除判据；5% 是团队可调整的建模规则，不是统计显著性标准。

尚未运行完整模型，因此目前没有证据证明被暂缓的所有变量影响小。先完成可执行简化模型，再只对可能改变结论的少数假设测试。对于已知重要但数据不足的因素，采用代理、区间或情景，不以数据缺乏为理由设零。
