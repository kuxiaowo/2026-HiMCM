# 2026-10-06修改可行性核查资料

本目录保存本轮取得的公开资料和下载请求记录。未覆盖既有原始资料；新资料尚未进入正式模型。

- `download_manifest_batch*.json`：请求URL、时间、HTTP状态、文件大小及成功文件的SHA-256。失败记录不代表资料不存在。
- `dnpwc_gis_database_final_2020.pdf`：47页官方GIS数据库报告，封面Bhadra24,2077；不是旧公园目录的CNP基础设施2022报告。
- `iucn_traffic_cop20_analyses_v4.pdf`：2025年CoP20提案分析；PDF第93页转载埃托沙象3266头的政府估计，未提供替换2015分区表的完整矩阵。
- `rhino_movement_2019.html`：原始研究；定位数据不公开的声明保留。
- `yellowstone_wolf_1995_2022.zip`：NPS官方历史狼群领地；本轮读取2022年10个95%MCP，不当当前分布或密度。
- `yellowstone_wolf_cougar_elk_2025.pdf`：2025年NPS年报。年报与旧GIS年份分别记录。
- `yellowstone_park_roads_2026.html`：2026计划道路开放规则；天气变化和应急权限仍需区分。
- `yellowstone_science_reports.html`：可用的NPS科研目录。`yellowstone_wolf_gis.html`虽返回200，实际是占位页，不作目录证据。
- `chitwan_tiger_dryad.html`、`dryad_file_4813216_meta.json`：公开虎数据目录及主CSV大小/指纹。
- `dryad_data_csv_public_preview.txt`：公开预览的文本响应，作为数据读取而未执行其中的JavaScript。正式CSV下载失败，输出目录只保存48条完整预览及其范围标记。

原报告年份、当前统计口径、部分预览与完整数据必须区分。详细判断见[本轮核查报告](../../../docs/modeling_notes/revision_data_feasibility_20261006.md)。
